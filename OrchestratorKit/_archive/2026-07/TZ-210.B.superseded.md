# TZ-210.B — Utility Classes & Global Styles (Logomock Integration)

**Статус:** 📋 Новое
**Родитель:** TZ-210
**Зона:** `frontend/src/styles.css` — `@layer base`, `@utility`, scrollbar

---

## 1. Цель

Добавить utility-классы и глобальные стили из макета, которые не зависят от конкретных токенов но улучшают визуальное качество.

---

## 2. Добавления в `@layer base`

### 2.1 Глобальный border-color

Добавить в `@layer base` (после существующих правил):

```css
/* === Universal border-color (Logomock — TZ-210.B) === */
* {
  border-color: var(--color-rule);
}
```

**Важно:** Это правило уже частично применяется через `hairline` utility. Добавление `*` rule ensures что ВСЕ элементы с `border` автоматически получают правильный цвет границы в обеих темах.

### 2.2 Body transitions

Добавить в существующий `html, body` правило:

```css
/* Добавить к существующим свойствам body: */
transition: background-color 0.2s ease, color 0.2s ease;
-webkit-font-smoothing: antialiased;
```

**Эффект:** Плавный переход между темами при переключении dark/light.

### 2.3 Heading typography

Добавить в `@layer base`:

```css
h1, h2, h3, h4, h5, h6 {
  font-family: var(--font-display);
  letter-spacing: -0.02em;
}
```

**Примечание:** У нас уже есть `--font-display: 'Hanken Grotesk'`. Это правило ensures что все заголовки используют display-шрифт с tightened tracking (как в макете).

## 3. Добавление `executive-shadow` utility

Добавить после существующих `@utility` определений:

```css
/* === Executive Shadow (Logomock — TZ-210.B) ===
   Selective shadow for cards, panels, elevated surfaces.
   NOT a global shadow ban override — specific opt-in only. */
@utility executive-shadow {
  box-shadow: var(--shadow-executive);
}
```

**Использование:** `<div class="executive-shadow">` на карточках, панелях, диалогах.

---

## 4. Обновление `eyebrow` utility

Изменить `letter-spacing` с `0.05em` на `0.08em`:

```css
@utility eyebrow {
  font-family: var(--font-mono);
  font-size: 11px;
  text-transform: uppercase;
  letter-spacing: 0.08em; /* TZ-210.B: updated from 0.05em per Logomock */
  color: var(--color-muted);
}
```

## 5. Кастомный scrollbar

Добавить в `@layer base` (или верхний уровень):

```css
/* === Custom Scrollbar (Logomock — TZ-210.B) ===
   Sleek 6px thin scrollbar for technical/editorial feel. */
::-webkit-scrollbar {
  width: 6px;
  height: 6px;
}
::-webkit-scrollbar-track {
  background: var(--color-paper);
}
::-webkit-scrollbar-thumb {
  background: var(--color-rule);
  border-radius: 3px;
}
::-webkit-scrollbar-thumb:hover {
  background: var(--color-muted);
}

/* Firefox scrollbar */
* {
  scrollbar-width: thin;
  scrollbar-color: var(--color-rule) var(--color-paper);
}
```
