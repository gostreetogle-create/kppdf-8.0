## 1. Контекст

TZ-202.A отложен (DEFERRED 2026-07-25) потому что audit `docs/data-model-audit.md §4.7` claim был **naming-mismatch**: `OrderHistory`, `UserActivity`, `Comment` schemas физически отсутствуют в `backend/src/modules/`. Этот successor-TZ ждёт product decision о необходимости unified audit-log. Pre-flight §4 step 1 является решающим — если хотя бы 1 source schema absent на момент выполнения, TZ маркируется DONE по TZ-201 / TZ-200.A doc-only pattern.

## 2. Проблема

Per audit, 3 source entities записывают смежные domain events: status changes (OrderHistory в order/), user actions (UserActivity в user/), comment threads (Comment в interaction/). Отсутствие unified schema приводит к: (1) дублированию логики (3 разных audit-trail patterns), (2) затруднённому compliance reporting, (3) невозможности cross-entity audit queries ("all actions on Procurement order #42" требует 3 разных запросов).

## 4. Action Steps

1. **Pre-flight check (REJECT if FAIL):** подтвердить наличие ВСЕХ 3 source schemas:
   - `ls backend/src/modules/order/order-history.schema.ts` → must return 0 (file exists)
   - `ls backend/src/modules/user/user-activity.schema.ts` → must return 0
   - `ls backend/src/modules/interaction/comment.schema.ts` → must return 0
   Если хотя бы 1 возвращает non-zero (file missing) → TZ-DONE по precondition-absent pattern. Audit doc §4.7 обновить accordingly. Skip steps 2-7.

2. Создать `audit-log.schema.ts` (см. §3). Compound index `(entityType, entityId)` + `actor` + `timestamp` descending.

3. RBAC: `@Roles('admin')` на `POST /audit-logs` per TZ-91 §2. Read endpoints public-with-auth (any authenticated user).

4. Migration `migrate-auditlog-unify.ts`: для каждой source entity → для каждой записи insert AuditLog doc. Pre-count assertion: 3 distinct source collection counts → expected AuditLog insert count = sum of 3 counts.

5. Sandwich-check после inserts: AuditLog count == expected; provenance counter per doc marked (e.g., `payload._provenance='OrderHistory'`).

6. Optional: keep source schemas as derived views (`schema.virtual('auditLog').get(function() { ... })`).

7. Update `docs/data-model-audit.md §4.7` status to DONE + cross-reference link to archive.
