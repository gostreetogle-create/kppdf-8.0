# TZ-211 — Apply Design System to DocumentConstructor (Builder Page)

**Статус:** 📋 Новое
**Родитель:** TZ-210 (Design Audit)
**Зона:** `frontend/src/app/pages/doc-constructor/builder/` — Angular компоненты

---

## 1. Контекст

После интеграции дизайн-токенов из Logomock (TZ-210.A/B) нужно применить визуальные паттерны к конструктору документов (BuilderPage). Logomock(DocumentConstructor.tsx) демонстрирует следующие элементы:

1. **Top Banner** — заголовок с статус-бейджем, view-mode toggle (Редактор/Preview), кнопка экспорта
2. **Block Structure Panel** — левая панель: список блоков + кнопки добавления + динамические переменные
3. **Active Block Editor** — центральная панель: форма редактирования выбранного блока
4. **Totals Panel** — правая панель: итоговый расчёт (НДС, скидки, итого)
5. **View Mode Toggle** — переключение между Редактором (3-pane) и Превью (A4 canvas)
6. **Executive Shadow** — тень на центральной панели
7. **Gold Accent** — золотой цвет для активных элементов и кнопок экспорта

---

## 2. Текущее состояние BuilderPage

BuilderPage (`builder.page.ts`) уже имеет 3-pane layout:
- **Tool Pane** (левая) — палитра блоков (тексты, таблицы, отступы)
- **Canvas** (центр) — рендер блоков на холсте
- **Inspector** (правая) — свойства блока/шаблона

Но визуально не использует новые токены (paper-3, paper-4, executive-shadow, gold-hover).

---

## 3. Что нужно сделать

### 3.1 Top Banner с view-mode toggle

В `builder.page.ts` добавить переключатель "Редактор" / "Превью PDF":
- Использовать существующий `viewMode` signal (или добавить новый)
- Toggle-бар с `paper-3` фоном и `hairline`边界
- Активная вкладка: `paper` фон + `ink` текст + `gold` нижняя линия
- Кнопка "Сформировать PDF" с `gold` фоном и `gold-hover` hover

### 3.2 Executive Shadow на Canvas

В `builder-canvas.component.ts`:
- Добавить `executive-shadow` класс к обёртке canvas
- Использовать `--shadow-executive` токен

### 3.3 Paper-3/Paper-4 для панелей

Все панели (Tool Pane, Inspector, Block Editor) использовать:
- `bg-paper-2` для фона панели (как в Logomock)
- `bg-paper-3` для header'ов панелей и hover-состояний
- `bg-paper-4` для активных элементов (выбранный блок)
- `border-paper` для `hairline` границ

### 3.4 Block List с hover-эффектами

В левой панели (Tool Pane) для списка блоков:
- Hover: `bg-paper-3` фон
- Выбранный блок: `bg-paper` + `border-gold` + `shadow-sm`
- Кнопки "+ Текст", "+ Таблица": `bg-paper` + `hover:bg-paper-3` + `hairline`
- Динамические переменные: `bg-paper` + `hover:bg-paper-3` + `hairline`

### 3.5 Totals Panel (правая панель)

Применить к панели итогов:
- `executive-shadow` на整个 панель
- Золотой итог: `text-gold` + `font-extrabold`
- Кнопка печати: `bg-gold` + `hover:bg-gold-hover` + `text-black`

### 3.6 View Mode Preview (A4 Canvas)

В режиме Preview:
- Тёмный фон: `bg-paper-4` (в dark mode) или `bg-[#1e232a]`
- A4 лист: `bg-white` + `shadow-2xl`
- Стили печати: Times New Roman, border-collapse, etc.

## 5. Принципы

1. **НЕ переписывать** — только добавлять CSS-классы и токены к существующим компонентам
2. **Использовать существующие токены** — paper-3, paper-4, gold, gold-hover, executive-shadow, hairline
3. **Consistency с Logomock** — визуальные паттерны должны совпадать с макетом
4. **OnPush + signals** — не нарушать существующую архитектуру
5. **Dark mode** — все изменения должны работать в обеих темах
