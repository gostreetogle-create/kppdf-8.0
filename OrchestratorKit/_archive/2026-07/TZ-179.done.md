# TZ-179 — Cleanup frontend `any`-typings and lifecycle (Sentry + rich-text)

**Дата:** 2026-07-25
**Тип:** Frontend hygiene (low-effort, high-cleanliness)
**Priority:** 🟢 MEDIUM
**Status:** ⏳ READY
**Layer:** 1 (Frontend Core)
**Agent Role:** Frontend junior engineer
**Estimated complexity:** S (<1 day)

## 1. Контекст

Two minor convention violations found в audit:
- `frontend/src/main.ts:10` — `(window as any).__SENTRY_DSN__` для global injection.
- `frontend/src/app/shared/ui/pi-rich-text-editor.component.ts:463` — `ngOnDestroy(): void` для Cleanup.

ARCHITECTURE.md §2.1 запрещает `any`, требует `DestroyRef.onDestroy()` pattern.

## 2. Проблема

| File | Line | Issue |
|---|---|---|
| `frontend/src/main.ts` | 10 | `(window as any).__SENTRY_DSN__ as string \| undefined` — double-`any` mapping. |
| `frontend/src/app/shared/ui/pi-rich-text-editor.component.ts` | 463 | `ngOnDestroy(): void` — should use `inject(DestroyRef).onDestroy()` per project convention. |

## 3. Файлы

### Files to modify
- `frontend/src/main.ts`
- `frontend/src/app/shared/ui/pi-rich-text-editor.component.ts`

### Files NOT to modify
- Sentry SDK init code (`sentry.init` config) — orthogonal concern.

## 4. Action Steps

1. Read `frontend/src/main.ts:1-30` для Sentry global injection context.
2. Replace `(window as any)` with declarative global type extension:
   ```typescript
   declare global {
     interface Window {
       __SENTRY_DSN__?: string;
     }
   }
   ```
   at top of `main.ts`. Then `const sentryDsn = window.__SENTRY_DSN__;` clean.
3. Read `pi-rich-text-editor.component.ts:455-475` ngOnDestroy body.
4. Replace class lifecycle: `inject(DestroyRef).onDestroy(() => { ...existing body... });` — same body, different placement.
5. Typecheck + lint.

## 5. Acceptance Criteria

1. `grep -nE "as any" frontend/src/main.ts frontend/src/app/shared/ui/pi-rich-text-editor.component.ts` → 0 hits.
2. `grep -nE "ngOnDestroy|implements OnDestroy" frontend/src/app/shared/ui/pi-rich-text-editor.component.ts` → 0 hits.
3. `pnpm exec tsc --noEmit -p tsconfig.app.json` exit 0.
4. Browser smoke: rich-text editor opens, edits content, closes без console errors.
