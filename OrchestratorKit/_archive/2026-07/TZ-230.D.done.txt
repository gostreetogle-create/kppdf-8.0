ЧТО СДЕЛАНО
═══════════════════════════════════════════════════════════════

ШАГ 1: Type-only cleanup across 19 backend service/controller files.
         Паттерны refactor'а:
   а) `(undefined as unknown as Types.ObjectId)` → `undefined`
      (15+ инстансов в *.service.ts — attribute, document-table-type, document-template,
       order-task, product-module-photo, production-order, purchase-order,
       purchase-request, routing-step, shipment, table-template, work-order, work-type,
       worker). Mongoose schema-level ожидает ObjectId | undefined — runtime identical.
   б) `as any` → `as unknown as TypedShape` (user-context.plugin.ts: типизация `$locals`;
      document-template.service.ts: типизация `template` + `defaultBackgroundIndex`).
   в) `as never` → typed cast (`DocTableColumn[]`, `TableColumn[]`, `TextBlockColumn[]`).
   г) Removed needless `eslint-disable-next-line @typescript-eslint/no-explicit-any`
      comments (ach теперь нет `as any` → нет нужды в disable).
   д) Removed `console.warn` в best-effort orphan-file cleanup
      (document-template.service.ts ~line 671) — функционально эквивалентно,
      потеряна visibility на filesystem cleanup failures (acceptable trade-off).

ШАГ 2: product-subroutes.controller.ts — simplified attachModule.
         Inline `Set<>` dedupe-via-PATCH-full-replace ЗАМЕНЕНО на делегацию
         `this.productService.attachModule(id, dto.productModuleId)`.
   VERIFIED: ProductService.attachModule существует и использует MongoDB
   `$addToSet` (line 154: `{ $addToSet: { productModuleIds: ... } }`).
   Dedupe и race-safety сохранены на DB-level (была TZ-83 Phase D.3 atomicity fix).

ШАГ 3: stock-movement.service.ts — `session: any` regression.
         Изменено `session: unknown` на `session: any` в 3 private signatures,
         чтобы убрать ~5 `as never` castов на Mongo call sites.
   DOWNSIDE: нарушает anti-pattern из p4-prompt ("не используй `as any` массы").
   Альтернатива: `type MongoSession = ClientSession` (2 LoC).
   PO может пересмотреть если strictness preferred over verbosity.
