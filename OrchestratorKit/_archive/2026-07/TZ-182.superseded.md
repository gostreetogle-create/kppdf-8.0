# TZ-182 — Swagger gating API (TZ-91 Phase C)

**Дата:** 2026-07-25
**Тип:** API documentation gating + DTO enrichment
**Priority:** 🔵 MEDIUM
**Status:** ⏳ READY
**Layer:** 4 (Backend API documentation)
**Agent Role:** Backend API engineer
**Estimated complexity:** M (1-3 days)

## 1. Контекст

`ARCHITECTURE.md` §4 OPEN Q: **TZ-91 Phase C (Swagger gating)** planned, not yet done. Swagger docs default-on в проектном bootstrap, что означает API documentation доступна в production (information leak risk). Per TZ-91 §Defense-in-depth: `if (process.env.NODE_ENV !== 'production' || process.env.SWAGGER_ENABLED === 'true')` должен gating по env flag.

## 2. Проблема

| Issue | Detail |
|---|---|
| Swagger docs always-on | `backend/src/main.ts` (verify — likely `SwaggerModule.setup` unconditional). |
| DTOs missing `@ApiProperty()` | Many DTO fields lack proper Swagger schema declarations → empty in UI. |
| Bearer auth not declared | `@ApiBearerAuth()` missing на security-required endpoints. |
| Response types generic | `@ApiResponse({ status: 200, type: X })` sporadic. |

## 3. Файлы

### Files to modify
- `backend/src/main.ts` (conditional Swagger setup)
- `backend/src/modules/*/dto/*.ts` (gradual `@ApiProperty` enrichment)
- `backend/src/modules/auth/dto/*.ts` (priority — auth endpoints used by everyone)

### Files NOT to modify
- NestJS swagger module version.
- OpenAPI spec generation tooling если separate.

## 4. Action Steps

1. Read current `backend/src/main.ts` Swagger bootstrap.
2. Wrap `SwaggerModule.setup(...)` в conditional:
   ```typescript
   const isSwaggerEnabled = process.env.NODE_ENV !== 'production' 
     || process.env.SWAGGER_ENABLED === 'true';
   if (isSwaggerEnabled) {
     SwaggerModule.setup('api/docs', app, document);
   }
   ```
3. Add `@ApiBearerAuth()` decorator на top of each `*.controller.ts` class (inherit global, but explicit per TZ-91 §security).
4. For high-priority DTOs (RegisterDto, LoginDto, CreateContractDto, etc.) — add full `@ApiProperty({ description, example })` decoration.
5. Test: change `NODE_ENV=production` и reboot → /api/docs returns 404.

## 5. Acceptance Criteria

1. `grep -A 5 "SwaggerModule.setup" backend/src/main.ts` shows conditional gating.
2. `NODE_ENV=production node backend/dist/main.js` запущен → GET `/api/docs` returns 404.
3. `NODE_ENV=development node backend/dist/main.js` запущен → GET `/api/docs` returns 200 + 200+ endpoint documentations.
4. `pnpm exec tsc --noEmit` exit 0.
5. DTO coverage: `grep -c "@ApiProperty" backend/src/modules/auth/dto/*.ts` — minimum 4 hits on key auth DTOs.
