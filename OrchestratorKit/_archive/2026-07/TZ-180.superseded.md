## 1. Контекст

TZ-91 Phase B (planned в `ARCHITECTURE.md` §4 OPEN Q) требует `@Roles()` sweep на **73 controllers**. TZ-171 handles 2 critical unprotected (cost-comparison, registry). TZ-180 covers **Core + Counterparty domain** batches.

## 2. Проблема

Контроллеры в scope (предположительно все `@Roles`-deficient или `@Public`-deficient на write paths):
- `backend/src/modules/audit/*.controller.ts`
- `backend/src/modules/auth/*.controller.ts` (special: `@Public()` для login/register/refresh/logout)
- `backend/src/modules/permissions/*.controller.ts`
- `backend/src/modules/role/*.controller.ts`
- `backend/src/modules/users/*.controller.ts`
- `backend/src/modules/counterparty/*.controller.ts`
- `backend/src/modules/organization/*.controller.ts`
- `backend/src/modules/person/*.controller.ts`

## 3. Файлы

### Files to modify
Все из списка выше. Audit ручной: прочитать каждый хендлер, добавить `@Roles('admin', 'manager')` или `@Public()` по TZ-91 §2 Decision 9 hierarchy.

### Files NOT to modify
Sales-side controllers (TZ-181 covers separately).
Production-side controllers (TZ-181).

### Conflict Keys
Sub-batches for parallelism:
- **Auth batch:** auth + permissions + role (system-related — careful).
- **Identity/Org batch:** users + organization + person.
- **Counterparty batch:** counterparty alone.

## 4. Action Steps

1. Read each controller handler-by-handler.
2. Classify read vs write vs system.
3. Apply `@Roles()` per TZ-91 hierarchy:
   - `@Roles('admin','manager','user')` для customer-facing reads.
   - `@Roles('admin','manager')` для operational writes.
   - `@Roles('admin')` для system config.
4. Update `e2e` specs если ещё нет видимости 403.

## 5. Acceptance Criteria

1. `grep -cE "@(Roles|Public)" backend/src/modules/audit backend/src/modules/auth backend/src/modules/permissions backend/src/modules/role backend/src/modules/users backend/src/modules/counterparty backend/src/modules/organization backend/src/modules/person` — каждый файл ≥1 hit.
2. E2E suites для этих модулей PASS (existing + new 403 tests).
3. `pnpm exec tsc --noEmit` exit 0.
