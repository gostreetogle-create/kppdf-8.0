# Audit — Desktop IA: что накидали и как разложить

**Дата:** 2026-08-16  
**Статус:** предложение PO (без кода)  
**Сейчас в UI:** 3 вкладки — «Студия импорта» | «MCP» | «Модель» + паринг сверху.

---

## Вердикт коротко

Накидали по делу, но **экран перегружен**: подключение, ручной импорт, агентский inbox, формы Excel, MCP и локальная модель живут рядом без явных «дверей».  
Север Desktop правильный: **тяжёлое и пакетное — на ПК, сайт — повседневная работа, SoT один (Nest)**.

Дублей write-path нет (HITL / Policy A). Дубль **ощущения** есть: «куда жать» и «нужен ли MCP для формы/модели».

---

## Предлагаемая карта (3 двери)

| Дверь | Русское имя | Что внутри |
|-------|-------------|------------|
| 1 | **Подключение** | Паринг к сайту, статус «кто я», кнопка связать/отвязать. Без этого запись на сайт закрыта; скачать Excel-форму — можно. |
| 2 | **Работа вручную** | Формы Excel (скачал→заполнил→загрузил) + drop своего файла + сопоставление колонок + отправить/отчёт. Главный путь менеджера. |
| 3 | **AI и агенты** | (а) Локальная модель: папка моделей, скачать, запустить, открыть папку. (б) MCP для Cursor/LM Studio: порт, копировать mcp.json, inbox агента. Подсказки: «без модели импорт тоже работает». |

Имена вкладок сейчас («MCP», «Модель») — для инженера. Для цеха лучше: **Подключение | Импорт | AI**.

## Что чинить в ближайшей волне (не фантазии)

1. **IA-shell** — три двери + короткие подсказки на кнопках (TZD-54).  
2. **Модель в установленном Desktop** — ошибка `Не найден каталог desktop: path does not have a parent` (раннер ищет исходники, в NSIS их нет) — TZD-55.  
3. **Кнопка «Открыть папку моделей»** рядом со «Скачать модель» (сейчас есть только у Inbox).  
4. **0.5.5 publish** — когда VPN off + «кати» (закрытие TZD-53 deploy).

## Идеи «на потом» (парк, не в эту волну)

- Вкладка **проверки сайта** (smoke API/экранов) — полезно, но это уже «лаборатория», не цех.  
- Тяжёлая аналитика / парсинг PDF пачками — да, на Desktop; после стабильного импорта.
