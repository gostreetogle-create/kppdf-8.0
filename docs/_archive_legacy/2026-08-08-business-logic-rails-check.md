**Зачем:** проверить, что поток «КП → заказ → цех → склад/отгрузка» не противоречит сам себе и боли PO (Excel-хаос → единая база → меньше ручного ввода → следующий шаг сам напрашивается).

## 5. Чего не хватает для автоматизации следующих шагов

Минимум данных (уже в модели / добить дисциплиной ввода):

1. **Изделие/модуль:** состав + виды работ + часы + (себест. через ставки).  
2. **КП→Заказ:** какие изделия и qty (есть).  
3. **Заказ→цех:** видеть раскрытый состав (**302**).  
4. **Люди + доступность** → Гант.  
5. **Материалы на складе** → reserve (после 302).  
6. **Статус заказа / CTA** «Следующий шаг» (тонкая TZ после 302) — подсказка, не новый модуль.

Не хватает **не** новых сущностей ради сущностей, а **склеек** и одного экрана «заказ целиком».
