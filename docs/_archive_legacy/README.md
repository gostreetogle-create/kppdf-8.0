# Legacy Documentation Archive

This directory stores historical journals, handoffs, superseded audits, and status snapshots that are not part of the operational agent context.

## Current sources of truth

- Agent queue and claims: `docs/agent-checklists/_NOW.md` + `tasks/_active/`
- Stable PO and product rules: `docs/PO-CANON.md`
- UI stop-rules: `docs/ui-rules.md`
- Runtime UI tokens: `frontend/src/styles.css`
- System refactor record: `SYSTEM-REFAC-REPORT.md`

Files in this directory are retained for audit/history only. Do not use them as current implementation guidance without checking the live canon and code.
