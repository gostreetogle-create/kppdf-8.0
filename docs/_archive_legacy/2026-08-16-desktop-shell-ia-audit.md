# Audit — Desktop shell IA (наслоение вкладок)

**Дата:** 2026-08-16  
**Источник:** диктовка PO после 0.5.4/Forms; VPN on → deploy не в скоупе  
**Код:** `desktop/src/App.svelte` — сейчас 3 вкладки: «Студия импорта» | «MCP» | «Модель»

---

## Verdict (человеческий)

Да, накидали по делу, но **раскладка устарела**: движки (MCP + локальная модель) и работа (Excel/формы/inbox) стоят как равные вкладки. Новичок не понимает «сначала подключись, потом работай». Дублей write-path нет — путаница в **навигации и названиях**, не в двух базах.

Север Desktop (канон) остаётся: **тяжёлый ввод и AI рядом с файлами**, сайт — повседневная работа. Не превращать Desktop во второй ERP.

## Предложение раскладки (тонкая оболочка)

**1. Подключение**  
Сайт (паринг) · MCP (Cursor/LM Studio) · Локальная модель (скачать / папка / статус).  
Короткие кнопки: «Подключить сайт» · «Запустить MCP» · «Скачать модель» · «Открыть папку моделей».

**2. Работа вручную**  
Скачать форму → заполнить → загрузить → проверить → подтвердить.  
Без MCP-терминов.

**3. Работа с агентом**  
Inbox · «Открыть папку inbox» · статус MCP chip · задачи для ИИ.  
Понятно: сюда кидаешь файлы для Cursor.

Имена можно сменить на твои («Настройки» / «Импорт» / «Агент») — смысл тот же.
