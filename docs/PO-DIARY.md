## 1. Кто такой PO (канон)

- Владелец небольшого цехового ERP (**~10 пользователей**): сварка / покраска / дерево / отгрузка / КП / офис-документы.
- Сам будет **показывать продукт коллегам** — планка «не позориться завтра на работе», а не «демо для инвесторов».
- Хочет **почти нормальный рабочий продукт** на текущих страницах, а не бесконечный backlog фич.
- Говорит потоком; ценит, когда агент **сам дожимает нюансы**, которые PO назвал бы «мелочью», но которые ломают доверие (контраст, gap, сессия, lock, пустые подсказки).
- Повторять одно и то же ненавидит: после сессии инсайт должен **остаться в репо**, не в голове модели.

## 2. Какая планка качества (канон)

| Да | Нет |
|----|-----|
| Мышью «чётко»: drag/resize/lock без сюрпризов | Half-baked ветки, «потом доделаем» на экране показа |
| Тёмная **и** светлая тема читаемы | Мрамор/шум/каракули, gold-on-white без контраста |
| Сессия переживает F5 / короткий блэкаут бэка | Выкинуло на логин «просто так»; зомби без «Выйти» |
| Пустые состояния говорят *куда кликнуть* | Текст «палитра выше», когда палитра слева |
| Превью = смотреть, не править | В превью всё ещё можно кидать блоки |
| Один тост на проблему | Спам тостов на каждый PATCH |
| FE+BE деплоятся согласованно | Новый UI + старый API → 400 на показе |

Правило показа: перед деплоем агент **сам** ищет то, чем PO стыдно будет перед коллегами, и чинит до «VPN выключи».

## 3. Север продукта (канон)

- ERP для **цеха**, не бухгалтерия и не тяжёлый зоопарк ACL «кнопка×кнопка».
- Документы / конструктор шаблонов — витрина аккуратности: каталог → builder → превью.
- Вертикали доводить до «можно жить», параллель — максимум 1–2 потока (см. peer/roadmap дискуссии).
- Осознанный отказ лучше недоделки: пример 2026-08-03 — **свободный текст «на лету» в палитре не делаем** (хватает каталога + «Редактировать»).
- Автологин без пароля / «всегда админ» — **нет**.

## 4. Как PO хочет работать с ИИ (канон)

1. **Понять намерение раньше кода.** Технически агент и так может собрать UI; ценность — угадать *зачем* и *насколько чисто*.
2. После обсуждения — **дожать и закрыть день** (полировка + gates), не оставлять «почти».
3. Деплой: агент говорит «готов» → PO выключает VPN → деплой; не торопить вслепую.
4. Документация живая: page.md / DARK-THEME / progress + **этот дневник**.
5. Cursor historically = архитектор/TZ; если PO явно сказал «сделай / добей / почини» — исполнять по смыслу сессии, не прятаться за Mode A в ущерб показу.
6. Коммиты — только когда PO просит (кроме политики Cursor на *свои* docs/TZ, если она активна).

### Антипаттерны (раздражают)

- Спросить то, что уже ясно из контекста дня.
- Сделать «фичу ради фичи» без сценария коллеги за монитором.
- Оставить ломающий WIP в `main` / смешать FE-only деплой.
- Длинный отчёт вместо короткого вердикта + что сделать PO.

## 5. Лог сессий (новые сверху)

### 2026-08-03 — Конструктор, тема, сессия, pre-deploy pride

- Цель дня: конструктор шаблонов «как взрослый продукт» + не стыдно показать коллегам завтра.
- Понравилось: мышь/геометрия, тёмная тема, светлая «вроде починили» — дальше сам аудит агента.
- Отклонено: free-text on the fly; passwordless admin.
- Важно: lock геометрии (поставить → закрепить); без случайного сдвига; превью чистое.
- Сессия должна жить в браузере (refresh 30d / не сбрасывать токены на 5xx).
- Убрать marble scribbles; semantic цвета иконок (delete/edit/copy); dense builder без щели под nav.
- Pre-deploy: зомби-auth, копирайт «палитра слева», preview read-only, toast spam, active templates, contrast ink-on-gold.
- Мета: «сам бы сделал, если бы ИИ понимал чего хочу» → заведён этот дневник + ритуал обновления.
