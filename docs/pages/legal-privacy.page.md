# Страница: Политика обработки персональных данных (`PrivacyPage`)

**Краткое описание:** Публичная страница с текстом политики ПДн.

## Route

```
/legal/privacy — «KPPDF — Политика обработки персональных данных»
```

Вне app-shell и вне authGuard (публичная).

## Особенности

- Текст политики содержит формулу: «Внутренняя информационная система. Доступ только уполномоченным лицам по приглашению администратора. Не публичный сервис и не рекламная площадка.»
- Без cookie-баннера, без analytics.
- Ссылка на эту страницу добавлена на страницы `/enroll` и `/login`.
- На сервере (nginx) путь `/legal/` настроен без `auth_request`, чтобы быть доступным анонимно.
