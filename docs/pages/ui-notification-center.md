# UI: Notification Center (колокольчик)

**Канон PO (2026-08-08):** тосты быстро пропадают → важные события
дублируются в **колокольчик** справа в шапке; список с крестиком;
кольцо **20** (FIFO: вытесняется самое старое).

**Код:**
- `PiNotificationCenterService` — `shared/ui/notifications/`
- `app-pi-notification-bell` — в `AppLayout` header
- Тосты (`PiToastService`) зеркалят сюда (`kind: 'toast'`)

## Поведение

1. Клик по колокольчику → панель со списком (новые сверху).
2. Открытие панели = все прочитаны (badge гаснет).
3. Крестик на строке = удалить одно; «Очистить» = всё.
4. `kind: 'message'` зарезервирован под переписку менеджеров (позже).

## Не делать

- Серверный inbox / WebSocket в Phase 1.
- Спам success на каждый PATCH — по-прежнему один тост на проблему (PO-DIARY).
