# Foundations page (`/foundations`)

Kit styleguide: palette swatches, type samples, spacing/radius.

## Typography (shipped)

- **Display:** Hanken Grotesk (`--font-display`)
- **Body:** Inter (`--font-body`)
- **Mono:** JetBrains Mono (`--font-mono`) — eyebrows / tech labels / IDs

ERP type scale: micro 11px → meta 12px → body 14px → title 16–18px → display-erp-max 20px.  
Canon: `docs/design-spec.md` · `frontend/src/styles.css` («ERP type scale»).

> Stale names Syne / Plus Jakarta Sans / Source Serif / Work Sans must not appear in page hints.
