# Gemini peer — Desktop вкладка «ИИ» UX (2026-09-06)

Превью-скрин: `docs/peer/evidence/gemini-desktop-ai-ux-preview.png`  
Промпт: `docs/peer/PROMPT-GEMINI-DESKTOP-AI-UX.md` §1  
Статус Cursor: **принят как целевой layout**, с правками ниже.

## Что сделал Gemini (сжато)

### Layout (~1100×700, Paper & Ink)

1. **Зона MCP сверху** (~52–60 px): статус ●/○, URL `127.0.0.1:3100/mcp`, primary «Скопировать mcp.json», secondary «Перезапустить».
2. **Зона чата** — остаток высоты: шапка одной строкой статуса модели + лента + input снизу.
3. Спеки ПК / TokenRouter / каталог моделей / сырые логи → **«Параметры и спеки»** (шторка), не на первом экране.

### Компоненты (имена для исполнителя)

- `McpStatusBar` — StatusDot, EndpointCopyInline, ButtonPrimary/Secondary  
- `ChatContainer` — ChatHeaderBar, MessageFeed, MessageBubble, ChatInputBar  
- `AssistantStateNotice` — 4 состояния  
- `AdvancedSettingsModal` — диагностика

### Microcopy (канон RU)

| Роль | Текст |
|------|--------|
| Контуры | ИИ · MCP-сервер для Cursor · Чат на этом компьютере |
| MCP OK | ● MCP-сервер работает (порт 3100 · N функций ERP) |
| MCP stop | ○ MCP-сервер остановлен |
| Primary | Скопировать mcp.json |
| Secondary | Перезапустить сервер |
| Не установлен | Локальный помощник не установлен. Для работы офлайн требуется загрузка файлов (~2 ГБ). |
| CTA install | Установить помощника (2 ГБ) |
| Загрузка | Загрузка компонентов модели (42% из 2.1 ГБ) · Скорость ~12 МБ/с |
| Ошибка | Не удалось запустить локального помощника. Освободите память или повторите запуск. |
| CTA error | Повторить запуск |
| Placeholder | Задайте вопрос по заказу, остаткам на складе или смене… |

### Антипаттерны (обязательны)

- Нет фиолетового AI-неона / sparkles  
- Нет стека ошибок / тройных плашек  
- Нет слов «раннер», «инференс», «GGUF» на главной  
- Нет каталога из 15 моделей  
- Не смешивать с «Подключение» / «Импорт»  
- MCP не в модалке — всегда верхняя плашка

### Эстетика из ответа

- Бумага `#FAF9F5` / `#EFECE6`, hairline `#D0CBC0`, чернила `#1B1C1E`  
- Скругление bubble ~4px, без градиентов

## Правки Cursor (не копировать слепо)

1. **Desktop уже имеет свои вкладки** (Подключение / Импорт / ИИ). Не рисовать в AI-экране ERP-вкладки «Заказы / Склад» — это чужой chrome из концепта.
2. **Сейчас (TZD-75):** зона чата = одно спокойное состояние **«Скоро»** (без «Установить», без «Повторить», без input). Кнопки скачивания ломают демо.  
   Целевые 4 состояния AssistantStateNotice — только после **TZD-76** (acceptance из `gemini-desktop-ai-runner-plan.md`).
3. Порт MCP брать из **реального** конфига Desktop, не хардкодить 3100 в UI-копирайт если порт другой.
4. Превью Gemini показывает «модель готова» + таблицу цеха — это **мок**, не текущий продукт.
