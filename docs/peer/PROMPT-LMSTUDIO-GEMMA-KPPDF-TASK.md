# Промпт для LM Studio (Gemma) — тест на kppdf

Вставь в чат LM Studio целиком. Потом ответ → Cursor.

```text
Ты помогаешь с цеховым ERP kppdf-8.0 (Nest + Angular NX + Desktop Tauri).
Код на диске D:\kppdf-8.0. Отвечай по-русски, коротко, без выдуманных API.

Задание (тест):
1) Объясни своими словами, чем отличаются вкладки Desktop «Импорт» и «ИИ» (MCP vs чат).
2) Где в продукте журнал закупок вместо Google Sheets (путь/страница), и что делает «Получено».
3) Напиши 5 шагов, как менеджер сопоставит колонки Excel через Desktop (HITL, без silent write).

Если не знаешь точный путь файла — скажи «не уверен», не выдумывай.
```

Усложнение (второй заход): приложи кусок `docs/audits/2026-09-06-supply-google-sheets-to-nx-audit.md` §1–2 в контекст LM Studio и спроси план Excel path A.
