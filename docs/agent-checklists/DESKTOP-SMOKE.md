## Install

- [ ] ZIP имя содержит `v0.5.6`
- [ ] После установки футер = **v0.5.6** (не 0.5.4)
- [ ] «AI» → «Локальная модель» — статус без «path does not have a parent»

## Подключение

- [ ] Паринг JSON → Подключиться → статус «Подключено»
- [ ] (Prod) compat-баннер если версия старая

## Импорт

- [ ] Формы: категория → скачать → загрузить → preview
- [ ] CAD xlsx (Tigran): сопоставление, confirm состав **без** массового missing_name
