`activeCategory` inside `studio-data-panel.component.ts` was a private signal
with no `@Input` — the host editor had no way to command "open category X" from
outside. Added `StudioDataPanelCategoryJump { category, nonce }` as a proper
input + constructor `effect()`; `nonce` exists specifically because Angular's
input change detection would otherwise silently no-op a second jump to the
*same* category (Client then Payer, both `whom`) — value-equal strings compare
equal, an object with an incrementing `nonce` never does.
