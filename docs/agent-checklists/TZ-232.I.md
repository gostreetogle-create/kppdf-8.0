## Scope

Two custom ESLint rules enforced via a local plugin (`frontend/eslint/rules/`),
enforcing TZ-232 architectural constraints at lint-time:

1. **`kppdf-frontend-architecture/no-raw-http-in-components`** — forbid `HttpClient`
   import + `this.http.<verb>(...)` raw calls in `*.page.ts` + `*.component.ts`.
   All HTTP in component files must go through `defineEntity()` services (TZ-232.B)
   or `httpResource()` signals (Angular 20 signal-based fetch).
2. **`kppdf-frontend-architecture/no-implements-oninit-in-pages`** — forbid
   `implements OnInit` (and other lifecycle interfaces) on `*.page.ts`.
   Pages must use `effect()` or constructor-time initialization; lifecycle hooks
   belong in infrastructure-layer services only.

These are the **enforcement seam** that prevents reintroduction of legacy / unsafe
patterns previously fixed during Wave A migration (TZ-232.A/N/B/C).
