# Смоук-тест: рабочее место КП (для менеджера)

> **Когда:** после волны workspace (гейт PO — cutover **408**, до деплоя **409**).  
> **Где:** `/proposals/workspace?new=1` (или `?id=` для черновика). Демо `/proposals/demo-workspace` — только геометрия, не этот прогон.  
> **Как:** мышь + глаза менеджера; 15–20 мин. Отмечай **PASS** / **FAIL**; при FAIL — одна строка «что не так».  
> **Связано:** полный E2E PDF/многостраничность — [`KP-E2E-SMOKE.md`](./KP-E2E-SMOKE.md).

| № | Шаг | Ожидание | PASS / FAIL |
|---|-----|----------|-------------|
| 1 | Открыть новое КП | Видны номер/дата; **понятно, сохранено ли** («Сохранено» / «Сохраняю…» / «Черновик»); на иконках боковой панели есть **подсказки** при наведении | |
| 2 | Шаблон | В **ленте сверху** — только **текущий** шаблон; **выбор** — в **левой панели** «Шаблон»; не два одинаковых входа с разным поведением | |
| 3 | Наша фирма | В ленте **заметно**, какая фирма выбрана; рядом или по подсказке видно **НДС / наценку** (если у цеха две фирмы — переключение без сюрприза) | |
| 4 | Клиент | Клик по **«Клиент» в ленте** открывает **панель «Клиент»** (объект, контакт); **быстрое создание** нового клиента **без ухода** в раздел «Клиенты» | |
| 5 | Каталог | Добавить 2–3 позиции «+ в КП»; **итого ₽ в ленте** обновляется сразу; после **F5** позиции на месте | |
| 6 | Геометрия листа | Открыть/закрыть **левую** и **правую** панель (в т.ч. **таблица**); лист A4 **не прыгает и не сжимается** (портрет и альбом) | |
| 7 | Таблица | После правки колонок/ширины — **«Применить и закрыть»** или клик мимо; на листе видно результат; панель не «висит» без понятного выхода | |
| 8 | Параметры | В одном месте видны **скидка** и **наценка фирмы**; не нужно искать по разным углам | |
| 9 | Условия | **Аванс %** и **срок производства (дней)** — рядом с текстом условий, не оторваны в «Параметрах» | |
| 10 | Печать / PDF | При **несохранённых правках каталога** в строках — **предупреждение** перед печатью/PDF; кнопки **Печать** и **PDF** только в **ленте**, отдельной кнопки «Вывод» на боковой панели **нет** | |

## Три обязательных риска (из приёмки Studio)

- [ ] Правка цены/названия в строке **не переписала** справочник без подтверждения  
- [ ] Быстрый клиент на входящем звонке — **без** ухода из КП  
- [ ] **Масштаб фото** и **шрифт таблицы** под A4 доступны (длинные названия не ломают лист неожиданно)

## STOP — не блокирует приёмку workspace

- Обрезка очень длинного описания на второй странице (отдельная задача wrap)  
- AI-черновик шаблона (волна 406+)
