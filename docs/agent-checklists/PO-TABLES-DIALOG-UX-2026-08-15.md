# PO checklist — Документы → Шаблоны таблиц (диалог колонок)

> Источник: диктовка PO 2026-08-15. Экран: `/doc-constructor/tables` → диалог шаблона.
> Проверено в коде: `table-template-dialog.component.ts` (кнопки, confirm, поля колонки).
> Статус: разбор DONE → правки через **TZ-DOC-TABLES-309** (ниже). Шрифт — отдельное решение.

## 1. Размер шрифта колонки (4…N)

| | |
|---|---|
| Нашёл ли PO | Нет |
| В коде таблиц | **Нет.** У колонки шаблона таблицы есть: `key`, `label`, `type`, `width`, `align`. Поля `fontSize` нет (ни FE, ни BE schema). |
| Где шрифт уже есть | **Текстовые блоки** (`/doc-constructor/texts` → редактор): выпадающий список 6…32. |
| Вердикт | Ты не «не понял меню» — в **таблицах** выбора шрифта просто нет. Добавить = новая фича (schema + UI + печать/PDF), не косметика. |
| Решение | **Сейчас не в 309.** Если нужно — отдельная TZ-DOC-TABLES-310 после твоего «да, шрифт в таблицах тоже». |

## 2. «+ Добавить столбец» (ключ / название / тип)

| | |
|---|---|
| Что делает | Добавляет **пустую** колонку в шаблон. Не подтягивает строку товара сама по себе. |
| `ключ` | Техническое имя поля (латиница). Для КП канон: `productName`, `quantity`, `unit`, `unitPrice`, `sum`, `index` — по ним Create КП знает, что подставить. |
| `название` | Заголовок на бланке (русский текст для человека). |
| `тип` | Как рисовать: Текст / Число / Валюта / Дата / Да-Нет. |
| Свой ключ | Можно. Тогда это «свободная» колонка: данные не из каталога автоматически — либо пусто/ручной сценарий, либо позже bind. Не мусор, но без понятного ключа пользы мало. |
| Вердикт | Функция **рабочая**, но UI не объясняет. В 309: подсказки RU + короткая строка-справка под кнопкой. |

## 3. «Пресет КП» / «каноном КП»

| | |
|---|---|
| Что делает | Подставляет готовый набор колонок КП (№, Наименование, Кол-во, Ед., Цена, Сумма). Если колонки уже есть — спрашивает замену. |
| Почему путает | Слово **«пресет»** — англицизм; «канон КП» — жаргон разработчика. Кнопки слиплись с «+ Добавить столбец». |
| Отмена | Правильно: ничего не меняет. |
| Вердикт | Не убирать кнопку. **Переименовать** на понятный русский + ясный confirm. |

## 4. Высота блоков редактирования колонки

| | |
|---|---|
| Где | Шапка таблицы в диалоге: поля `ключ` / `название` (и тип). |
| Боль | Поля низкие, неудобно целиться/читать. |
| Вердикт | Косметика UI — **в 309** (выше input / padding шапки колонки). |
