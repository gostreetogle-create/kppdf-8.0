# Brief: Density Canon — готовы к отмашке

> **Статус:** READY, волна выдана (FORM-308 Claude · 309/310 Freebuff).  
> Внешний концепт «две панели ERP» — про стол, не про FullEditor; в эту волну не смешивать.

## Берём (в существующие файлы, не новый kit)

| Правило | Куда |
|---------|------|
| Ширина **окна** ≠ ширина **поля**. Поле = ожидаемая длина значения | `ui-form-field-capacity.md` (снять «только kind B») |
| Короткие фикс. значения: control `max-w` / `ch` (как GOV.UK 2–20 символов), не full-width | `field-capacity.ts` `CAPACITY_CONTROL_MAX_CLASS` — расширить на kind C |
| Переменные поля (имя, select, адрес) — 12-col span | уже есть; то же для FullEditor |
| Д/Ш/В + вес — **одна лента** (band) | уже `BAND_START_KEYS`; обязательно и в kind C |
| Textarea: мало строк (3–5, QC ≤2), не высота под maxLength 4000 | cookbook + capacity |
| Overlay ~70vh, sticky footer, скролл только body | уже kind C; не копировать % Carbon |
| Анти: числа на всю ширину, «всем 50%», пустое описание толкает «Сохранить» вниз | явный НЕ в каноне |

## Не берём

- Авто-правило «12–15 полей / 3 секции → уйти на страницу». Ориентир в тексте, не гейт. Сначала упаковка.
- Modal height 48/72/84/96% Carbon.
- Auto-grow textarea как обязательный примитив (нет в kit → позже).
- Третий «density token» compact/comfortable на весь сайт.
- Новый UI-kit.

## Изделие остаётся диалогом (kind C)

После packing body **должен влезать без скролла на 1440**. Если конкретный редактор всё равно не влезает — вкладки/секции в том же окне. Страница — крайний случай по одному редактору, не отмена kind C.

Один реестр `FIELD_CAPACITY` на QuickCreate **и** FullEditor (не две таблицы).
