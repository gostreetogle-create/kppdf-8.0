## Канон движка

Локальная модель Desktop — **уже вшитый** `node-llama-cpp` (TZD-55/56), файлы **`.gguf`**
в `appData/models`, HTTP OpenAI-совместимый на `127.0.0.1:9744`.

**Не** ставим Ollama вторым движком. **Не** сливаем с LM Studio / Cursor MCP
(блок «MCP для агентов» остаётся для внешних клиентов).

Второй **источник чата** (не второй движок): любой OpenAI-совместимый HTTP
(`/v1/chat/completions`) — TokenRouter free и аналоги. Карточка на вкладке AI,
не четвёртая дверь. Канон полей: URL + ключ + id модели. TZ: **TZD-65**.
Текст чата при этом уходит с ПК — баннер, без ПДн клиентов.

Паттерн UX как у Handy: статус → нет файла → папка или скачать → чат. Начинка — своя.

## Цель PO

Нажал «Чат» / открыл вкладку AI → модель в памяти, можно писать.
Нет файла → открыть папку моделей (флешка: скопировал `.gguf` сюда) **и** кнопки
скачать из каталога Hugging Face. После скачивания — сам загрузил, без «Сначала
раннер, потом скачать, потом Перезапустить». Настройки проекта — сами
(LIMITED_HELPER, без ручного baseUrl/ключа).
