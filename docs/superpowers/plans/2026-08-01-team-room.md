# Team Room Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with review and verification gates.

**Goal:** Build a dependency-free local Team Room that starts automatically when an agent joins, coordinates task claims across linked worktrees, and provides a browser chat/dashboard.

**Architecture:** A Node.js standard-library HTTP process binds to `127.0.0.1`, serializes state updates, and persists JSON outside Git worktrees under the user-local application-data directory. A CLI starts/reuses the process and provides agent commands; a static browser dashboard consumes the same API.

**Tech Stack:** Node.js 20+, `node:http`, `node:fs`, `node:test`, plain HTML/CSS/JavaScript. No new package dependencies, database daemon, Docker service, cloud account, or remote network access.

## Global Constraints

- Team Room is loopback-only.
- Existing source code, task archives, and Git history are never modified automatically by the service.
- All linked worktrees for one repository share one room; unrelated repositories use separate state.
- Claims must reject duplicate task ownership and overlapping conflict keys.
- Leases expire after inactivity and must be visible in the activity history.
- `join` is idempotent and does not open a browser for every agent; `open` is the human-facing dashboard command.
- Agent instructions must require automatic join/check-in so the owner does not need to remember a separate step.
