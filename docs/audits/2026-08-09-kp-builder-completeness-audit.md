## 1. Вердикт в пяти строках (для PO)

1. Наш «скелет» **лучше** аналога там, где живой каталог: витрина изделий, шаблон-бланк из
   конструктора, колонки таблицы, наценка/НДС в подвале. Это не переделывать.
2. **Стопперов пять:** нельзя увидеть и поправить список добавленных позиций; нет PDF/печати;
   нет клиента-получателя на бланке; нет коммерческих полей (предоплата, сроки, скидка, дата);
   нет блока «Условия» в самой студии.
3. Половина недостающего **уже есть в таблицах** (`title`, `date`, `validUntil`, `discount*`,
   `notes`, `versions`) — не сделан UI. Меньшая часть требует новых полей.
4. Расположить всё **некуда добавлять новые экраны**: хватает верхней строки студии, левого
   рейла (+ Получатель) и правого рейла (+ Состав, + Условия) с секциями по смыслу.
5. Итог оформлен волной **WAVE-KP-COMPLETE** — TZ-SALES-340…348.

## 3. Куда это кладётся в нашем интерфейсе

Новых экранов не заводим — студия уже трёхзонная (спека `docs/ux/kp-create-studio-spec.md` §0 FROZEN).

**Верхняя строка студии** (сейчас там только «Сохранено»):
`КП-026` · название · бейдж статуса · «Сохранено» · **Версии (N) ▾** · **Сохранить версию** ·
**Скачать ▾** (PDF · Печать · В архив документов).

**Левый рейл — «что кладём в КП»:** Шаблон · Товары · **Получатель** (новая иконка).

**Правый рейл — «как считается и как выглядит»:** **Состав** (новая) · Параметры · Таблица ·
**Условия** (новая).

**Секции внутри «Параметры»** (по категориям, а не одной простынёй):

| Секция | Поля |
|---|---|
| Документ | Номер · Название · Дата · Срок действия · Тип документа |
| Стороны | Наша фирма · Получатель (короткая строка + «Открыть») |
| Деньги | Наценка % · Скидка (%/₽) · НДС % · Сбросить · **Итого** |
| Сроки | Предоплата % · Срок изготовления · Срок поставки |
| Вид листа | Строк на 1-й / след. странице · Размер фото % · Обрезка фото % · Колонка фото |

Правило рейла: панели остаются взаимоисключающими overlay (317/332), лист A4 не сжимается.

## 4. Осознанно НЕ делаем (границы)

- **Почта/отправка клиенту и публичная ссылка** — нет SMTP-модуля и нет решения PO по домену;
  «отправлено» пока остаётся ручным статусом.
- **Валюта и мультивалютность** — цех работает в ₽; хардкод оставляем.
- **Редактор бланка внутри студии** — верстка живёт в конструкторе шаблонов, студия только
  выбирает бланк и правит экземпляр (канон `2026-08-09-kp-table-config-canon.md`).
- **Скидки в каталоге** — скидка живёт только в КП, полку не трогаем (канон sales-to-shop-flow).
- **Аналитика «клиент открыл КП»**, электронная подпись, согласование — вне цеха ~10 человек.
