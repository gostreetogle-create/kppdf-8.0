# Create КП — вывод: печать свободная, жёсткие гейты только на lifecycle

**PO 2026-08-12:** на всех кнопках Вывода тост «Дождитесь готового превью и выберите нашу фирму» — бесит; для простой печати это заглушка не по делу.

## Север

| Действие | Смысл | Гейты |
|----------|--------|-------|
| **Печать** | «Хочу увидеть/отпечатать что на экране» | Только: есть HTML превью. **Не** требовать фирму, **не** форсить save перед print |
| **PDF** (скачать файл) | Нужен id на сервере | Мягко: если draft уже есть — PDF; если нет и можно сохранить — сохранить затем PDF; если нельзя (нет шаблона/фирмы) — **понятное** «для файла PDF нужна фирма и шаблон», не тот же текст что у печати |
| **Архив документов** | Копия в приложении | Как PDF: нужна сохранённая сущность |
| **Смена статуса / заказ / «оплачено»** | Lifecycle | Тут уместны **предложения**: чего не хватает, чтобы шагнуть дальше (клиент, позиции, фирма…) |

Автосохранение черновика **не** смешивать с кнопкой Печать.

## Позже (не блокирует печать)

На ключевых переходах lifecycle (сейчас разумная точка — **Принято**; «Оплачено» если появится в статусах) — **автоматически** класть PDF-снимок на сервер (версия .1 / .2 при повторном входе в то же состояние). Отдельная TZ после стабилизации статусов на Все КП.

## Баг сейчас

`requestOutput` для **всех** action зовёт `canSaveDraft()` → один тост → печать без фирмы невозможна, даже если превью уже на экране.
