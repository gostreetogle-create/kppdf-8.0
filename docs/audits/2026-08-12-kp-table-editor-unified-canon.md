# КП «Редактор таблицы» — канон merge Состав + Таблица (2026-08-12)

**Север:** «Редактор таблицы» — единственное место, где менеджер собирает строки этого КП
и там же решает, как они лягут на бланк. Лист A4 = зеркало (смотреть), не рабочая поверхность.

| Дубль | Где сейчас |

Итог для менеджера: два меню про одно и то же → «куда идти править».

## 2. Компоновка (canon)

Flyout ≈ ширина A4 (`min(794px, calc(100% - rails))`), overlay, блоки сверху вниз:

1. **Строка состояния:** «Редактор таблицы» · N позиций · Итого. Один хинт, не два.
2. **Toolbar (вид, фон raised):** `Колонки ▾` · Рамка тонкая|обычная|жирная · Шапка обычная|жирнее ·
   `Таблица бланка ▾` (только если таблиц позиций > 1) · `⋯ Ещё`.
   В `⋯ Ещё`: «Добавить поля КП (кол-во/цена)», «Открыть пресет в Документах», «Сбросить ширины».
3. **Полоса «Скрыто:»** — тонкая, появляется только при наличии скрытых колонок; чип = вернуть одним кликом.
4. **Hairline-разделитель:** выше — вид, ниже — позиции.
5. **Живая таблица** с зонами (микро-подписи над шапкой):
   - жёлоб слева: `↑↓`, `№` (служебное);
   - **«что видит клиент (на бланке)»** — колонки раскладки экземпляра;
   - **«только в КП»** (притенённый фон): скидка `%`, `Опц.`;
   - жёлоб справа: `✎` карточка каталога, `🗑` удалить.
6. **Footer:** `+ Своя строка` (full-width, dashed) → Итого / «опц. вне итога» / «скидка фоном и НДС — в Параметрах».

**Ключ merge:** настройка колонки живёт **в её шапке** (каретка → Левее · Правее · Ширина % · Скрыть).
Отдельный column strip упраздняется; скрытые колонки достижимы через полосу «Скрыто:» и `Колонки ▾`.

## 3. Что выкидываем / что остаётся один раз

**Выкинуть (дубли):**
- панель «Состав КП» как отдельный rail-пункт и её собственный header/hint/total;
- жёсткая шапка состава (`№ · Наименование · Кол-во · Ед. · Цена · % · Сумма · Опц.`) — её роль берут колонки бланка + служебные зоны;
- второй редактор qty/цены в Table Studio без скидки/суммы;
- блок `studio__columns` (chips-стрип) — переезжает в шапку колонок;
- `duplicate` строки (PO: «copy в составе непонятен») — не возвращать в v1.

**Оставить один раз:** живая таблица; qty / цена / сумма / скидка / опц. / ед. / описание / имя своей строки;
`↑↓`; `✎` каталог; `🗑`; «Своя строка» внизу; итог; toolbar рамка+шапка; селектор таблицы бланка;
«Добавить поля КП»; «Открыть пресет в Документах».

## 4. Рейл

`Параметры` · **`Редактор таблицы`** · `Условия`. Кнопки «Состав» и «Таблица» больше нет.
Слева без изменений: `Шаблон` · `Товары` · `Получатель`.
`rightPane`: `'params' | 'table' | 'terms'` (ключ `table` сохраняем, `composition` уходит).

## 5. Границы (НЕ)

- Никакой правки внутри iframe A4; лист остаётся `sandbox` превью.
- Никакого конструктора колонок уровня Документов (типы, формулы, источники) внутри КП.
- Ни одного PATCH в shared `TableTemplate` из КП — только переход по ссылке.
- Второй write-path строк запрещён: qty в «Товарах» = «сколько добавить», не редактор строки.
- DnD строк — опционально позже; `↑↓` достаточно для v1.
- Колонки скидки на бланке нет (скидка фоном) — она живёт только в зоне «только в КП».

## 6. Критерии приёмки (показ коллегам)

1. Правый рейл = 3 кнопки; tooltip/aria/заголовок = «Редактор таблицы»; «Состав» отсутствует в DOM.
2. Flyout ≈ A4, overlay: open/close не меняет ширину листа, содержимое не клипается.
3. Строки КП правятся только здесь (qty, цена, сумма, скидка, опц., ед., описание, имя, порядок, удаление).
4. Правка qty → живая таблица + Итого + A4 согласованы без «Показать»; одно значение, не две копии.
5. «Скрыть» из шапки убирает колонку и в редакторе, и на A4; чип в «Скрыто:», возврат одним кликом.
6. Ширина задаётся в шапке той же колонки; сумма видимых ширин нормализуется; пропорции на A4 те же.
7. Служебные зоны и «только в КП» отделены hairline + фоном и подписаны; на бланке их нет.
8. «Своя строка» — одна кнопка внизу; строка сразу в таблице, фокус в названии, попала на A4.
9. Рамка thin|normal|thick и шапка normal|bold совпадают в живой таблице и на бланке.
10. За сессию правок нет ни одного PATCH `table-templates`; пресет в Документах не изменён.
11. Read-only КП: поля, меню колонок и «Своя строка» disabled, `not-allowed`, без «провалов».
12. Пустой КП: подсказка «Добавьте изделия из «Товары»» + кнопка + скелет шапки бланка (не «Нет данных»).
13. Light + dark читаемы; chrome ≥ 11px; при 6 видимых колонках нет горизонтального скролла во flyout.

## 7. Фото на бланке (хвост волны)

«Фото» = обычная колонка раскладки (порядок / видимость / ширина). В ячейке — миниатюра из
`ProposalDraftLine.photoUrl`; на бланке высота ряда ~30 мм, лёгкая копия изображения (канон PHOTO-301),
при отсутствии фото — пустая рамка без битой картинки. Менять фото — только через `✎` (карточка каталога),
не в КП. Не раздувать этим первый экран merge.
