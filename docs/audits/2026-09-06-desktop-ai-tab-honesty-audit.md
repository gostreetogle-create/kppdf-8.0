## Для PO (просто)

**Надежда есть** — но не в виде «допилить все четыре квадрата».  
Сейчас на экране смешаны **три разных продукта**:

1. **Чат с локальной моделью** (нужен «раннер» = фоновый движок LLM на ПК) — у тебя **ломается** (порт/процесс), плюс слово «раннер» ни о чём.
2. **Модель по API** (облако/TokenRouter) — отдельный контур, на скрине почти пустой.
3. **MCP для агентов** — **работает** (зелёный «Запущен», копирование mcp.json). Это как раз мост Cursor/Claude к данным kppdf.

Импорт Excel **не зависит** от модели (баннер наверху прав).

**Удалять всю вкладку «ИИ»** — рано: потеряем рабочий MCP.  
**Оставить как есть** — стыдно на демо.  
**Правильный ход:** честный экран — сверху MCP (главное), локальный чат свернуть в «Скоро / не готово» или один понятный мастер «Скачать модель → Запустить помощника», без дублирующих красных ошибок. Слово «раннер» убрать → «Локальный помощник» / «Движок модели».
