# Аудит: карточка изделия — боковые панели + себестоимость

**Дата:** 2026-08-08  
**Триггер PO:** слева/справа каша текста; таблица себест. со скроллом; три цены непонятны; автопересчёт при изменении состава; состав **не трогать**.  
**Скрин:** product detail «Бордо…» / Выбрано «Демо · Панель».

---

## 1. Вердикт

| Зона | Проблема | Решение |
|------|----------|---------|
| Левый паспорт | Прайс / Себест / База / «В составе» без смысла; мелкий текст | Цены → блок **Себестоимость**; слева фото + имя + статусы + **габариты/вес/RAL** крупнее |
| Аккордеон «Себестоимость» | Широкая таблица → гориз. скролл | Вертикальный **стек фактов** / карточки снимков, без h-scroll |
| Пересчёт | Только кнопка | Авто **после успешного add/remove/qty** состава (debounce); кнопку оставить |
| Правый «Выбрано» | Текст и кнопки вразнобой; «Открыть карточку» строкой; **нет Редактировать** | Секции FactCard; все действия = **PiButton**; **Редактировать** → тот же FullEditor (модуль/изделие/материал); «Открыть карточку» отдельно |
| Состав (центр) | — | **НЕ в этой волне** (UX-312 отдельно) |

Канон переиспользования: общий примитив **Fact / Metric card** (`PiFactCard`) — потом sweep по сайту.

## 2. Что значат три цифры (зафиксировать в UI)

| Поле | Код | Коротко для человека |
|------|-----|----------------------|
| **Прайс** | `listPrice` | Цена витрины / для КП |
| **Себест.** | `costPrice` | Сколько изделие «стоит цеху» (rollup) |
| **База** | `basePrice` | Базовая цена учёта (до коммерции) |
| **В составе** | count lines | Не деньги — число позиций; оставить у паспорта как meta, не в ценовом блоке |

Показывать с **одной строкой-подсказкой** под цифрой (caption 11–12px). Не прятать смысл только в tooltip.

## 4. Автопересчёт себестоимости

- Триггер: успешный composition mutate (add / remove / patch qty) на **корне изделия**.
- Реализация: вызвать существующий recalculate API (тот же, что кнопка «Пересчитать»), `debounce` 300–500ms, не блокировать UI (toast/spinner на блоке денег).
- Не считать на каждый hover/select.
- Если API тяжёлый — один in-flight + очередь «dirty»; не спамить.

---

## 5. FactCard (UI kit)

Имя: **Fact card** (карточка факта) — `app-pi-fact-card`.

Содержимое: label (eyebrow) · value (крупно) · optional caption · optional actions slot.  
Варианты: `default` | `emphasis` | `danger` (для «Убрать»).  
Стек: `app-pi-fact-stack` с заголовком секции.

Эталон применения: inspector + блок денег на detail.  
Потом audit-sweep (отдельный TZ).
