# Аудит-коррекция: Create КП shell — overlay RMK (2026-08-09)

**Триггер:** PO после первой реализации 317 — «одна кнопка → две панели, центр дёргается».  
**Канон цели:** лист A4 в центре **не меняет размер**; меню открываются **поверх**.

## Ошибка первой итерации

| Сделали | Почему плохо |
|---------|----------------|
| Один left-icon → flyout с L1+L2 (две колонки) + шаблон сверху | Много горизонтали, «две панели», не RMK |
| `grid-template-columns` расширялся при open | Center **сжимался** — лист дёргался |
| Шаблон и товары в одном flyout | PO хотел **две кнопки** в rail: Шаблон / Товары |

## Правильный паттерн (POS / RMK / studio tools)

```
[📄]                 ┌── A4 fixed ──┐              [⚙]
[📦]  ─overlay→      │   не двигается│
                     └──────────────┘
```

1. **Фиксированный** каркас: `rail | center | rail` — колонки grid **никогда** не меняются.
2. Левый rail сразу **две** иконки: **Шаблон** · **Товары** (не одна «каталог»).
3. Правый rail: **Параметры**.
4. Flyout = `position: absolute` поверх center; клик вне / Escape → закрыть.
5. Одновременно один left-tool; на узком экране — ещё и не вместе с Right.
6. Выбрал шаблон → превью обновилось → панель **закрылась** (жест RMK).
7. Товары: панель остаётся открытой для «Добавить» подряд (add & continue).
