# Create КП — убрать savebar над A4 (канон PO 2026-08-12)

**Скрин / жест:** красный овал на полосе «Сохранено · Страница · Черновик · статус · Версии · Заказ · Копировать · Скачать»; A4 уезжает вниз + скролл.

## Север

Студия Create КП = **только сборка бланка**. Управление жизненным циклом КП — на **Все КП**.  
Center под chips: сразу `rail | A4 | rail`, **никакой** горизонтальной tools-полосы над листом. Никогда снова.

## Куда что

| Сейчас в savebar | Решение |
|------------------|---------|
| Сохранено / Автосохранение… | Убрать с UI. Autosave в фоне остаётся; ошибка — toast |
| Страница 1 из N | Убрать дубль (у каждой страницы уже есть label в center) |
| Бейдж статуса + «Изменить статус…» | Убрать → **Все КП** |
| Сохранить версию / Версии (N) | Убрать → **Все КП** (freeze уже там) |
| Создать заказ | Убрать → **Все КП** («В заказ») |
| Копировать КП | Убрать → **Все КП** |
| Скачать ▾ (PDF · Печать · Архив) | **Оставить смысл**, перенести в **icon-rail** (иконка «Вывод»), flyout |
| Вернуться к текущему (version view) | Убрать вход в version-view из студии; если deep-link останется — минимальный chrome без savebar |

Chips «Создать КП | Все КП» — **не** превращать в вторую toolbar. Пустой `[tools]` слот не рисовать.
