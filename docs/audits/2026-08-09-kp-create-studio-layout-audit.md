## 1. Вердикт по бизнес-логике

Идея студии **правильная** и совпадает с каноном продаж→цех (D13/D21):

| Зона | Роль менеджера | Сущность |
|------|----------------|----------|
| Центр | Смотреть **лист КП / шаблон** как документ | `DocumentTemplate` + draft lines |
| Лево | Брать **изделия** из каталога в draft | `Product` → in-memory lines |
| Право | **Бланк** (наша фирма), наценка, клиент | `Organization` / `%` / `Counterparty` |

Не возвращаемся к «тонкому диалогу = создать КП». Жёлтый chip **Создать КП** уже говорит, где мы.

## 2. Что ломает фокус сейчас (факт с экрана)

| Наблюдение | Доказательство |
|------------|----------------|
| Дубль заголовка «Создать КП» | H1 в toolbar + активный жёлтый chip |
| Лишние zone-titles | `Товары` / `Превью КП` / `Параметры` |
| Центр узкий | center ≈ **570px** при vw=1920; left 320 + right 340 всегда открыты |
| A4 не «лист» | preview sheet ≈ **544×224** — не высота viewport |
| Страница раздута | studio height ≈ **2124px** при vh=1080 — скролл из длинного списка товаров |
| Товары = длинный список | 30× «Добавить», не flyout / cascade |
| Desktop без collapse | `isWide()` → обе панели всегда open (SALES-312) |

Chrome сверху (глобальное меню + TOC КП/Договоры/Заказы + жёлтые chips) — **оставить**; режем только page-local мусор.

## 3. Целевой каркас (набросок PO)

```
┌─ app nav ───────────────────────────────────────────────────┐
│ Сделки › TOC: КП | Договоры | Заказы                        │
│            yellow: [Создать КП] [Все КП]                     │
├────┬───────────────────────────────────────────────────┬────┤
│ ▣  │                                                   │ ▣  │
│ 📦 │              ┌──────── A4 sheet ────────┐         │ ⚙  │
│    │              │  (шаблон КП целиком)     │         │    │
│rail│              │  top-aligned, fit viewport│         │rail│
│ ~48│              └──────────────────────────┘         │ ~48│
│    │              без page-scroll                      │    │
└────┴───────────────────────────────────────────────────┴────┘

LEFT expand (поверх / от рейла вправо — cascade):
┌────┬──────────┬──────────────┐
│ 📦●│ Категор. │ Изделия…     │  → клик вне → свернуть в rail
│    │ →        │ [Добавить]   │
└────┴──────────┴──────────────┘

RIGHT expand (от рейла влево):
                        ┌────────────┬────┐
                        │ Org / % /… │ ⚙● │  → клик вне → rail
                        └────────────┴────┘
```

**Приоритет места:** по умолчанию **обе** узкие icon-rails; центр максимален.  
Правую **держать свёрнутой**, пока не нужны параметры — чтобы левая витрина при раскрытии могла занять больше ширины.  
Если одновременно открыть обе — допустимо; при узком центре right принудительно закрывать.
