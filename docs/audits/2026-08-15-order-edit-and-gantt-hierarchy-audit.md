# Audit 2026-08-15 — Заказ: модель PO vs код + редактор

**Источник:** диктовка PO (КП→заказ→изделия→цех/Гант) + Save «ничего не происходит».  
**Аудит кода:** explore agent + `order-form-dialog` / `gantt-bar.model` / convert.

## 1. Твоя логика — что совпадает

| Ты сказал | В коде |
|-----------|--------|
| КП → (принято) → Заказ; покупатель = Counterparty | Да, `convert-to-order` |
| Заказ = 1+ **изделий (Product)** | Да, `Order.items[].productId` |
| Изделие → модули → виды работ → дни | Да в **каталоге**; на заказе BOM не копируется |
| Цех смотрит сроки видов работ | Да, `WorkType.days` + override заказа |
| Отгрузка позиции по умолчанию = «вместе» | Поле есть (`plannedShipDate`); дефолт из даты заказа — **нет** |

## 2. Где путаница имён (не баг домена)

На Ганте ▸ под заказом ты видишь **сварку/покраску** — это **виды работ**, не «паспорт» и не сам заказ.  
Иерархия **в данных:** Заказ → Изделие → Модуль → Вид работ.  
Иерархия **на экране Ганта сейчас:** Заказ → Вид работ (плоско). Изделие/модуль только в подсказке.  
Поэтому «сварка чего?» — справедливый вопрос; каскад Заказ→Изделие→… — **парк** (ниже).

## 4. Подтверждённые баги редактора заказа (чинить сейчас)

1. **Save мёртв на создании / новой строке:** `onProductPick` пишет имя, **не** `productId` → форма invalid → return без toast.  
2. **Объект пустой:** сайты грузятся только если у Counterparty уже есть Site; ensure-default как на convert — нет.  
3. **Freeze:** заказ `in_production`/`ready` — состав PATCH запрещён; форма шлёт всё → 400.  
4. **«Паспорт» / статус на Ганте:** статус в meta read-only; меняется в диалоге заказа (если не freeze).
