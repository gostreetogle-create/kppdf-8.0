# Plan reviews (parallel peer opinions)

Агенты **не** правят один общий plan-файл одновременно.

Каждый пишет **свой** файл сюда:

```
docs/audits/plan-reviews/firm-mega-<ваш-короткий-id>.md
```

Пример: `firm-mega-buffy.md`, `firm-mega-sol.md`, `firm-mega-explorer.md`.

Куратор (Cursor) потом сводит в план / lock.
