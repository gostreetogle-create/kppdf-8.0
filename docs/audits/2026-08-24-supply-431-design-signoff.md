## 2. Суть компактности (из wireframe PO — обязательно для кода)

**Главное отличие от текущего UI:** не три accordion-полосы «Позиция ▸ / Поставщик ▸ / Детали ▸», а **одна развёрнутая панель = 3 колонки сразу видны**. Смысл полей читается по **зонам A/B/C**, не по вертикальной простыне.

### 2.1 Принцип «категория полей → пара строк»

Каждая зона — **короткий столбец** (не больше ~5–6 строк контента). Внутри зоны поля **сгруппированы по смыслу** и **сжаты в 2-col пары** там, где логически связаны:

| Зона | Заголовок колонки | Строки (сверху вниз) |
|------|-------------------|----------------------|
| **A** | ПОЗИЦИЯ | ① Категория + `+` (full width) |
| | | ② Материал + иконки copy/pencil + `+` (full width) |
| | | ③ Ссылка на товар (full width, link icon) |
| | | ④ Артикул · ГОСТ **\|** Цвет / сплав (50/50) |
| | | ⑤ Кол-во **\|** Ед. изм. (50/50) |
| **B** | ПОСТАВЩИК И КОНТАКТ | ⑥ Организация + `+` + ссылка «Карточка» (full width) |
| | | ⑦ Сайт **\|** Email org (50/50, autofill) |
| | | — *hairline* — |
| | | ⑧ Контакт + `+` (full width) |
| | | ⑨ Тел **\|** Email менеджера (50/50, autofill) |
| **C** | ДЕТАЛИ | ⑩ Статус **\|** Приоритет (50/50, badge/dot) |
| | | ⑪ Нужно к **\|** Наша компания (50/50) |
| | | ⑫ Примечание (1–2 строки, full width) |
| | | ▸ Доп. параметры (collapsed): цена, дата заказа, ответственный |

**Anti-pattern (убрать):** отдельный label-остров на каждое поле («Организация», «Сайт», «Почта поставщика», «Контакт»…) с persist-hint абзацем между ними.

### 2.2 Визуальная иерархия

- Заголовки зон: **A / B / C** + короткий title (`ПОЗИЦИЯ`, `ПОСТАВЩИК И КОНТАКТ`, `ДЕТАЛИ`) — один раз на колонку, не дублировать subgroup-label на каждое поле.
- Label поля: мелкий muted (`text-xs`), значение — обычный контраст.
- Persist hint («сохранено в карточке»): **tooltip** на поле или одна строка под парой ⑦, не отдельный `<p>`.
- Hairline border между колонками и внутри B между org-block (⑥⑦) и contact-block (⑧⑨).

### 2.3 Реестр + разворот (как на макете)

```
┌─ mini-table (все строки) ─────────────────────────────────────────┐
│ ДАТА │ КАТЕГОРИЯ │ НАИМ │ КОЛ-ВО │ СТАТУС │ ПОСТАВЩИК │ ДЕЙСТВИЯ │
│ ... collapsed rows ...                                          │
│ ▾ EXPANDED ── footer: [Скопировать] [Удалить]    [Сохранить] ── │
│   ┌─ A ────────┬─ B ────────────────┬─ C ────────────┐          │
│   │ ①…⑤        │ ⑥⑦ | ⑧⑨           │ ⑩⑪⑫ + ▸ Ещё    │          │
│   └────────────┴────────────────────┴────────────────┘          │
└─────────────────────────────────────────────────────────────────┘
```

- Свёрнутая строка = **одна строка таблицы** (~36px), не отдельная «плитка с воздухом».
- Разворот **заменяет** строку таблицы на 3-col panel (или row-span под header).
- Верх expanded: **«Esc · Свернуть»** справа; низ: **Скопировать строку · Удалить** слеva, **Сохранить изменения** справа (mock: blur-save OK).

### 2.4 Совмещённость autofill (зона B)

Org и contact — **одна колонка**, не две секции с toggle:

1. Выбрал org → ⑦ заполняется сразу; ⑧ dropdown наполняется; если 1 контакт → auto ⑧⑨.
2. «Карточка» — текстовая ссылка рядом с ⑥ (read-only drawer), дублирует пункт меню `+`.
3. Редактирование ⑦/⑨ на месте → debounce save в org/Person (hint inline, не блок).

### 2.5 Опционально: «1→9 порядок заполнения»

Toggle в toolbar (dev или query `?fillOrder=1`): маленькие бейджи ①–⑫ на полях — **не** меняют layout, только подсказка PO «что после чего».

### 2.6 Desktop vs mobile

- **≥900px:** 3 равные колонки A|B|C, пары 50/50 внутри.
- **&lt;640px:** стек A→B→C; **B не разрывать** (⑥–⑨ подряд); пары остаются 50/50 где влезает.

## 5. PiSelectAddRow — org (2.4rem, `--color-sunrise-soft`)

Меню у поставщика:

1. **Новый поставщик** — inline panel ≤3 поля (Название, Сайт/Email, Тел) → `POST /organizations` `type: ['supplier']`
2. **Из наших организаций** — search picker всех org → confirm `[клиент] → [клиент, поставщик]` → `PATCH` append `supplier` → autofill cascade
3. **Карточка** — read-only drawer (ИНН, менеджеры)

---

## 6. Autofill states

| State | Поведение |
|-------|-----------|
| Empty | Поля очищены |
| Filled / Cascade | Org → site, email, contacts; Contact → phone, email |
| Saving | Debounce 400ms + blur → PATCH org/Person; hint «сохранено» |
| Error | Контурный акцент, не блок UI |

**Правило:** один контакт у org → auto-select.
