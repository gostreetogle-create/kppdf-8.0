# Audit: библиотека текстов vs «+ Текст» (2026-09-13)

## PO expectation

«+ Текст» → выпадающий выбор сохранённых текстов с фильтром по категориям/подкатегориям.

## What exists today

| Действие | Где |
|----------|-----|
| Сохранить | Выделить текстовый блок → **Свойства** → «Сохранить в библиотеку текстов» (диалог с обязательной подкатегорией) |
| Вставить из библиотеки | Уже есть текстовый блок → **Свойства** → Категория → Подкатегория → «Из библиотеки» (`studio-text-properties.component.ts`) |
| Каталог | Реестры → **Тексты** `/registries/text-blocks` · категории `/registries/text-block-categories` |
| «+ Текст» | Только пустой слой / фокус активного текста (`addTextToActiveLayer`) — **без** picker |

## Gap

Функция сделана (TZ-NX-TEXT-PICKER-FORM), но точка входа не там, где PO ищет (Элементы → + Текст). Discoverability fail, не отсутствие backend.

## Fix direction

На «+ Текст» открыть тот же picker (reuse logic), плюс пункт «Пустой текст». Свойства — оставить как apply-into-selected.
