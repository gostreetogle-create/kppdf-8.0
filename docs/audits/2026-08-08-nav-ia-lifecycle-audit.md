## 2. Сейчас (L→R как в коде)

```text
Каталог | Сделки | Производство | Склад | Справочники | Документы | Админ
```

| Категория | Пункты | Оценка |
|-----------|--------|--------|
| Каталог | Продукция, Модули, Материалы, Виды работ, Оформление, **Люди** | Полка ок; **Люди** — не каталог |
| Сделки | **Организации**, КП, Договоры, Заказы | Порядок КП→…→Заказы ок; **Организации** = наши фирмы, не заказчик |
| Производство | только Гант | Нет очереди проектировщика |
| Склад | Дашборд, Остатки, Движения, Склады | Нет Отгрузки; нет Снабжения |
| Справочники | Классификация, Измерения, Оформление, Документы-ref, Категории, Цвета… | Дубли путей; form-profiles ещё нет в меню |
| Документы | Шаблоны, тексты, таблицы, архив | Ок как витрина шаблонов |
| Админ | Users/Roles | Ок |

**FE:** маршрута `/counterparties` в `app.routes.ts` **нет** (API counterparty на бэке есть).

## 3. Целевое меню L→R (канон)

Смысл: **сначала готовим полку и клиентов → продаём → запускаем → обеспечиваем → делаем → храним/отгружаем → бумаги → доступ.**

| # | Категория (топ) | Пункты | Зачем |
|---|-----------------|--------|--------|
| 1 | **Справочники** | Классификация, Измерения, Цвета, ед., категории шаблонов/текстов, **Профили быстрых форм** (после 315) | Настройки «раз и настроили» — левее операционки |
| 2 | **Каталог** | Продукция → Модули → Материалы → Виды работ · Оформление каталога (admin) | Полка |
| 3 | **Клиенты** *(новая)* | Заказчики (Counterparty), Объекты/площадки (Site) | Единая база клиентов; не путать с Organization |
| 4 | **Сделки** | КП → Договоры *(опц.)* → Заказы | Продажа → в работу |
| 5 | **Проектирование** *(новая)* | Очередь «доукомплектовать» | Не готов к работе |
| 6 | **Снабжение** *(новая)* | Задачи закупки / подтверждения | D9 |
| 7 | **Производство** | Гант (+ later люди как подпункт) | Цех |
| 8 | **Склад** | Склады, Остатки, Движения, Дашборд · **Отгрузка** *(новая)* | Хранение + ship |
| 9 | **Документы** | Шаблоны, блоки, архив | Витрина/PDF |
| 10 | **Админ** | Пользователи, Роли · **Наши организации** (перенос сюда) · Люди *(или под Производство)* | Доступ и наши юрлица |

Хлебные крошки (`PiPageChrome`): `Раздел / страница` — уже канон; после NAV-301 разделы = имена категорий выше.

## 4. Переносы (было → стало)

| Что | Сейчас | Канон |
|-----|--------|--------|
| Люди | Каталог | **Производство** (подпункт) или Админ — default: **Производство** |
| Организации (наши фирмы) | Сделки | **Админ** (или Справочники «Наши фирмы») — default: **Админ** |
| Заказчики | нет в nav | **Клиенты** |
| Оформление | Каталог + Справочники | Каталог = appearance изделий; Справочники = цвета/классификаторы — **не два одинаковых ярлыка** |
| Категории vs classification | два входа | Один UX-вход «Классификация»; лишние leaf-ссылки убрать из топа (deep-link оставить) |
| Виды работ | Каталог | Оставить в Каталоге (PO diary) |
