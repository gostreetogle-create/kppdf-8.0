## Системные исправления (канонизировать)

1. **Один коммит = одна TZ.** Label коммита = ID TZ. Агенту запрещено
   объединять задачи разных TZ в один коммит даже в одной сессии.
2. **Spec-coverage гейт:** для каждого тронутого product `.ts` — найти все
   `*.spec.ts`, ссылающиеся на его селекторы/компонент
   (`rg "<ComponentName>|data-test=..." frontend/src --glob '*.spec.ts'`)
   и прогнать их. Затронул поведение — обнови все зависимые спеки в той же TZ.
3. **Перед «кати» — полные suite на целевом SHA**, не focused: FE jest целиком,
   BE jest целиком, результат зафиксирован в PRE-DEPLOY с точным
   `deploy_sha_target`. Focused — только внутри TZ.
4. **SHA-drift правило:** если `HEAD != deploy_sha_target` в момент кати —
   PRE-DEPLOY недействителен, таблицу пересобрать перед деплоем.
5. **Инвариант `_active` XOR `_archive`** — проверять скриптом/гейтом;
   done.md обязан содержать `sha:` и быть взаимоисключающим с active-файлом.
6. **Базлайн известных падений** вести списком имён (см.
   `tasks/PROMPT-DEPLOY-READY.md` § Базлайн) — чтобы отличать долг от регресса
   за минуту, а не через worktree-бисекцию.
7. **Desktop installer freshness:** mtime `frontend/downloads/*.zip` должен быть
   ≥ последнего коммита в `desktop/`; иначе пересборка ДО «кати» (~10+ мин),
   не во время.
