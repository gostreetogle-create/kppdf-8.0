# Create КП — flyout chrome marathon (2026-08-12)

## Север

Меню студии Create КП: **два размера**, одна логика краёв.

| Тир | Когда | Ширина (канон) | Панели сейчас |
|-----|--------|----------------|---------------|
| **S** | мало данных / выбор / короткая форма | `min(20rem, calc(100% - rails))` | Шаблон, Параметры, Условия |
| **L** | много данных / таблица / витрина | **один** токен `--kp-flyout-l: min(794px, calc(100% - rails))` | Товары, Редактор таблицы (после 359), Получатель* |

\*Получатель: сейчас узкий; канон → **L** (много полей клиента/контакта/объекта), чтобы левый край совпадал с большими панелями слева.

Большие панели **одинаковой ширины** и с одной привязкой к рейлу (`left: var(--kp-rail)` / `right: var(--kp-rail)`), без «прыжка» края при смене Товары↔Таблица.
