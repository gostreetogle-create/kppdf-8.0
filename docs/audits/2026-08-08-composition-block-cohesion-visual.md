## Канон (что меняем)

Техника expand/collapse, данные, клик по строке — **без изменений**.

Цель: при раскрытом изделии с несколькими модулями глаз сразу читает:

> вот **пачка модуля A** (рамка + её детали/материалы) · зазор · **пачка модуля B** · …

### Приёмы (Paper & Ink + kind)

1. **Sibling gap** между соседними nest-пачками: `12–16px` (сейчас куча слишком плотная).  
2. **Левый rail** у `.comp-tree__nest`: полоска 3px `catalogKindBorder(parent)` — «это один контейнер».  
3. **Indent** детей внутри nest: +`8–12px` вправо относительно строки родителя (лёгкий «сдвиг вглубь», не колонки Excel).  
4. **Wash** чуть сильнее внутри nest, снаружи листа — нейтральный paper (контраст пачки к фону).  
5. **Скругление + padding** nest: `rounded-md`, padding `10px 10px 10px 8px`.  
6. Не: толстые чёрные рамки с эскиза, не 3-колоночный layout, не тени-многослойки.

### Анти-куча (AC для глаза)

| Было | Стало |
|------|--------|
| Модули и материалы в одном визуальном потоке | Каждый раскрытый модуль = отдельная «карточка-пачка» |
| Маленький gap | Явный воздух между sibling-пачками |
| Слабая граница | Hairline + rail + wash читаются light/dark |
