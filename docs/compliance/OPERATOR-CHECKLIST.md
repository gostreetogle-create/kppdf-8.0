# Чеклист оператора ПДн (kppdf) — для PO

> Заполняется **владельцем** с юристом. Не генерировать «нейросетью без вычитки».
> Статус: шаблон; галочки PO ставит вручную (или в копии).

## A. Статус

- [ ] Определено **юридическое лицо / ИП** — оператор (из `Organization` на prod)
- [ ] Назначен **ответственный за организацию обработки ПДн** (приказ)
- [ ] Подано **уведомление** в Роскомнадзор (если нет освобождения по ст. 22 ч. 2)
- [ ] Получено / сохранено подтверждение подачи (номер, дата)

## B. Документы

- [ ] **Политика обработки ПДн** (опубликована на `/legal/privacy`)
- [ ] **Согласия** с сотрудниками (Worker/User) — отдельно от правил системы
- [ ] **Договоры / clauses** с контрагентами (обработка контактов Person/Counterparty)
- [ ] **Приказ** о доступе к ИС и audit
- [ ] **Регламент** утечек → `docs/ops/INCIDENT-PDN.md`

## C. Техника (сверка с prod)

- [ ] Mongo + uploads только **РФ** (`/var/lib/kppdf80`)
- [ ] `SENTRY_DSN` **пустой** или одобрен трансгран-пакет
- [ ] Нет Google Analytics / рекламных пикселей
- [ ] `POST /auth/register` **отключён**
- [ ] Backup-носители учтены как ПДn (шифрование / доступ)

- [ ] 24 ч: уведомление РКН об утечке (если применимо)
- [ ] 72 ч: подробный отчёт
