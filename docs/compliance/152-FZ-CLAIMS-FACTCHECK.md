# Fact-check: Instagram-пост про штрафы за «мини-проект за вечер»

> Дата разбора: 2026-08-18. Нормативная база: 152-ФЗ, КоАП ст. 13.11 (ред. с **30.05.2025**,
> ФЗ № 420-ФЗ от 30.11.2024), 38-ФЗ «О рекламе» (рассылки).  
> **Не юридическая консультация** — для решений нужен юрист по ПДн.

## Что в посте в целом верно

Пост бьёт в реальную боль: **многие « pet-проекты» уже обрабатывают персональные данные (ПДн)**,
а «доделаем юридическую часть потом» с 2025 года стало дороже. Диапазоны штрафов **часто
совпадают** с новой ст. 13.11 КоАП, но:

- суммы зависят от **состава** (часть статьи), **субъекта** (ИП/ЮЛ/ДЛ), **повторности**;
- с **30.05.2025** за многие первичные нарушения возможно **предупреждение** (ч. 1 ст. 4.1.1 КоАП);
- пост **смешивает** 152-ФЗ и рекламные рассылки (38-ФЗ / КоАП 14.3) — это разные режимы;
- «форма на сайте = оператор» — **верно по смыслу**, но оператором можно стать и **без публичной
  формы** (CRM, кадры, логи, cookies).

## Что в посте преувеличено или упрощено

1. **«Любая форма с именем/почтой/телефоном»** — достаточный, но не единственный триггер. Уже **логин сотрудника**, **ФИО в CRM**, **cookie device-grant**, **IP в audit log** — тоже ПДн.
2. **«152 закона»** — маркетинговый образ; на практике важны 152-ФЗ, КоАП 13.11, 38-ФЗ, отраслевые акты, приказы Роскомнадзора.
3. **Шаблоны «нейросетью без вычитки»** — риск реален (ошибки в целях, основаниях, трансграничности), но штраф привязан к **факту нарушения**, не к инструменту генерации.
4. **Закрытый invite-only ERP** снижает **публичные** риски (нет массового сбора с улицы), но **не отменяет** статус оператора, если в системе есть сотрудники и клиенты.

## Применимость к kppdf (кратко)

| Сценарий поста | kppdf сейчас |
|----------------|--------------|
| Публичная регистрация + маркетинг | **Нет** — `POST /auth/register` отключён (TZ-AUTH-308) |
| Форма с email/телефоном для всех | **Нет** на публичной поверхности; `/enroll` — только **имя компьютера** |
| Google Analytics / рекламные пиксели | **Не найдено** в FE |
| SMS/email-рассылки | **Нет** модуля рассылок |
| Трансгран | **Риск опциональный**: `SENTRY_DSN` (US SaaS) — по умолчанию **пусто** |
| Политика ПДн / согласия на сайте | **Нет** — gap |
| Уведомление Роскомнадзора | **Не в репо** — организационный gap (решает PO + юрист) |
| ПДн контрагентов/сотрудников в ERP | **Да** — Person, Worker, User, Counterparty, паспортные поля Organization |
