# Правила compliance для kppdf (152-ФЗ и смежное)

> Обязательны для **всех** TZ, деплоев и новых фич. Нарушение = STOP до правки спеки.
> Не заменяют юридический пакет (уведомление РКН, договоры, приказы).

## 1. Статус системы

- kppdf — **корпоративная ИС** (~10 пользователей), не публичный B2C-сервис.
- Публичная поверхность минимальна: `/enroll/*`, статика, API device-enrollment, health.
- **Текст «личный учебный проект»** (`login.page`, `home-host-access.md`) — **не** compliance-документ.

## 2. Персональные данные — что считаем ПДн в продукте

| Категория | Примеры в kppdf |
|-----------|-----------------|
| Идентификация | User.username, Worker ФИО, Person ФИО, deviceName |
| Контакты | email, phone (User, Person, Counterparty, Worker) |
| Документы | Organization.passport* (серия, номер, кем выдан…) |
| Технические | IP в AuditLog, cookies (`__Host-kppdf-device`, refresh), логи auth |
| Медиа | photoIds, attachments type `passport` |

Любая новая сущность/поле с ПДн → строка в матрице целей (см. §7) **до merge**.

## 3. Запрещено без отдельной TZ + юридической оценки

| Запрет | Почему |
|--------|--------|
| Google Analytics, Meta Pixel, Hotjar и любые **рекламные** счётчики | Трансгран + нет основания у посетителей |
| Публичная **регистрация** с email/телефоном | Массовый сбор; сейчас OFF — не включать |
| **SMS/email-рассылки** (маркeting, «новости», акции) | 38-ФЗ + отдельное согласие; модуля нет |
| Использовать контакт «для сделки» для **рекламы** | Цель обработки ≠ цель сбора (152-ФЗ ст. 5) |
| Согласие на ПДн **внутри** пользовательского соглашения одной галочкой | ст. 9 152-ФЗ |
| Публикация **ФИО/фото/отзывов** клиентов на сайте/KP без согласия на **распространение** | ст. 10.1 152-ФЗ |
| `SENTRY_DSN` / иностранный APM с **PII** в payload | Трансгран; по умолчанию DSN **пустой** |
| Primary Mongo / файлы ПДн **вне РФ** без процедуры ст. 18 | ч. 8–9 ст. 13.11 КоАП |
| Google OAuth / Sheets sync **с ПДн контрагентов** без оценки трансгран | Отложено PO; audit: `docs/audits/2026-08-16-google-sheets-bridge-audit.md` |
| Логировать **полные** тела запросов с ПДн в stdout/Sentry | Утечка + трансгран |

## 4. Разрешено при текущей модели доступа

| Разрешено | Условие |
|-----------|---------|
| Device invite + **имя компьютера** на `/enroll` | Ссылка одноразовая; после COMP-401 — текст + ссылка на политику |
| Password login **owner break-glass** | Не публичный self-service; учётная запись ограничена |
| Хранение ПДн **контрагентов и сотрудников** в Mongo на VM РФ | `/var/lib/kppdf80`; основание — договор/труд/законный интерес (оформляет PO) |
| AuditLog (userName, ipAddress) | Retention policy + доступ admin-only (COMP-402 successor) |
| Chromium **внутри** backend-контейнера для PDF | Обработка **не** у Google; рендер локальный |

## 5. Публичные страницы — минимальный UX (цель TZ-COMP-401)

На `/login` и `/enroll` (footer или aside):

1. Ссылка **«Политика обработки персональных данных»** (`/legal/privacy` или статика).
2. На `/enroll`: явный текст — **какие данные** (имя устройства, технические cookies), **зачем** (доступ к ИС), **кто оператор** (наименование из Organization).
3. **Не** требовать email/телефон на enroll.
4. Отдельное согласие — если юрист потребует для deviceName; не прятать в «принимаю правила».

## 6. Деплой и ops

- `SENTRY_DSN=` **пустой** на prod, пока нет трансгран-пакета.
- Новые `.env` ключи с иностранными API → строка в `docs/compliance/2026-08-18-project-pdn-audit.md` § changelist.
- При подозрении на утечку: **24 ч** уведомление РКН (ст. 21 152-ФЗ) — см. `docs/ops/INCIDENT-PDN.md` (создать в COMP-401/402).
- WIPE / экспорт БД — только по DANGEROUS-OPS; экспорт = носитель ПДn.

## 7. Матрица «цель — основание — срок» (шаблон для PO/юриста)

Заполняется вне кода; разработка сверяет новые поля с таблицей.

| Обработка | Цель | Основание (152-ФЗ ст. 6) | Срок | Где в коде |
|-----------|------|--------------------------|------|------------|
| Worker, Person | CRM, производство | Договор / исполнение договора | Договор + 3–5 лет* | worker, person modules |
| User (логин) | Доступ в ИС | Труд / согласие / договор поручения | Пока учётка активна | auth, user |
| Device grant | Запомнить браузер | Согласие / инструкция оператора | 365d default | device-enrollment |
| Counterparty контакты | Продажи, отгрузка | Договор | Договор + бух* | counterparty |
| AuditLog | Безопасность | Законный интерес / обязанность | TBD (COMP-402) | audit |

\* Сроки — placeholder; фиксирует юрист/бухгалтерия.
