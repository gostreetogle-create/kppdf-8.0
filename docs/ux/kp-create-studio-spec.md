# Создать КП — layout spec (WAVE-KP-VITRINE)

**Route:** `/proposals/create`  
**Chrome:** Сделки TOC (КП) + жёлтые «Создать КП» | «Все КП»  
**Обновлено:** 2026-08-09  
**Утверждение:** PO смотрит этот файл до/с TZ-SALES-312

## Цель

Один экран сборки КП: не диалог, а студия. Содержание одно; бланк = Organization; клиент = Counterparty.

## Desktop (≥1280px) — три колонки

| Зона | Ширина | Содержание |
|------|--------|------------|
| **Left — товары** | 280–320px, scroll | Поиск + список изделий/модулей; Add → строки draft |
| **Center — превью** | flex 1, min 480px | «Лист» A4-ish (max-width ~794px), шаблон + таблица позиций |
| **Right — инспектор** | 300–340px, scroll | Organization, % наценки, **оценка суммы** (подпись «оценка»), прочие dropdown |

Gap между колонками: 12–16px. Высота: под sticky group-chrome, body `min-h: calc(100vh - chrome)`.

## Tablet (768–1279)

- Center на всю ширину.
- Left/Right — кнопки «Товары» / «Параметры» открывают panel/drawer поверх или side sheet.
- Одновременно открыта ≤1 боковая панель.

## Mobile (<768)

- Center first.
- Bottom sheets для товаров и параметров.

## Open / close

- Desktop: колонки всегда видны.
- Узкие: `aria-expanded` на toggle; Escape закрывает drawer.
- Не перекрывать TOC/chips.

## Пустые состояния (RU, одна фраза)

| Зона | Текст |
|------|--------|
| Left | «Выберите изделие — оно попадёт в КП» |
| Center | «Выберите шаблон КП или добавьте позиции слева» |
| Right | «Укажите нашу фирму (бланк) и наценку» |

## Цены

Пересчёт на экране = **подсказка**. Сохранённый total с наценкой — не обязанность 312–315.

## Вне scope этого spec

Печать пачкой, встроенный builder, вторая витрина каталога.
