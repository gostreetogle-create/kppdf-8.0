# Кардинальные изменения — простым языком

> Когда меняется *что люди открывают / что исчезнет / риск данных* — сначала этот тон, потом пути TZ.  
> Общие правила «что придумывать»: [`PO-SHARED-UNDERSTANDING.md`](./PO-SHARED-UNDERSTANDING.md).

## Шаблон абзаца для PO (обязателен при кардинальном сдвиге)

1. **Что сейчас** (одним предложением).  
2. **Что станет** после работы.  
3. **Что не трогаем** (данные, другие экраны).  
4. **Зачем это оператору / показу** — или честно: «это не для оператора, предлагаю не делать».  
5. **Как откатить / отложить**, если передумал до исполнения.

Запрещено вместо этого: одна строка `PARK`, `SoT`, `decommission`, `legacy`, `blast radius`.

## Пример (разобранный антипаттерн, 2026-09-05)

**Плохо:** «P6 legacy Gantt decommission — не PARK, Да?»

**Суть факта:** вырезать старый Гант из `frontend/` куском, пока NX ещё не полный cutover.

**Честно для PO:** новому Ганту на NX это **не нужно**. Старый код — эталон до конца миграции. В финале папку `frontend/` и так уберут целиком (часто вручную). Частичный снос сейчас жег бы агентов без пользы цеху. **Не делаем.** Аудит: [`audits/2026-09-05-po-agent-shared-understanding-audit.md`](./audits/2026-09-05-po-agent-shared-understanding-audit.md).

## Живые кардинальные факты (коротко)

| Тема | Смысл |
|------|--------|
| Фронт | Финал = только NX (`MASTER-CORE`) |
| Старый `frontend/` | Эталон до cutover; не второй боевой сайт |
| Cutover | Целиком в конце; не partial-волны по умолчанию |
| Гант сейчас | Рабочий экран разработки = NX `:4201` |
| Локальные данные NX (2026-09-06) | Всё виртуально/демо; битые хвосты можно аккуратно вычищать; не значит «стереть всю базу на сервере» |
| Докум. шапка (2026-09-06) | Сейчас «Докум.» часто кидает сразу в редактор, сверху куча текстовых кнопок. Станет: список / шаблоны / студия отдельно; сверху только крошки; Сохранить/PDF и т.п. — в боковых иконках. Данные документов не трогаем — только навигация и шапка. Аудит + TZ: `audits/2026-09-06-docstudio-chrome-ia-audit.md` |
