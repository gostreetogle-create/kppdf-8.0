# Operator bar — что Cursor обещает по студии

> Я (Cursor) отвечаю за полноту **контура создания любых документов в NX `/studio`**.  
> Не за `/desk` MASTER-CORE и не за PARK (merge / Word / Excel-builder).

## Ментальная модель оператора

Чтобы **создать любой документ** и не стыдно показать коллеге, нужно:

| Шаг | Нужно | Покрытие |
|-----|--------|----------|
| 1. Начать | blank / из шаблона / дубль | list уже есть |
| 2. Тип документа | КП / договор / счёт / … | **S39** + shortcut КП **S33** |
| 3. Собрать лист | текст / таблица / фото / страницы | elements+layers — есть |
| 4. Подставить данные | клиент, якоря, **витрина**, КП/заказ | **S27–S29** |
| 5. **Гибкие токены** | ERP-поля ↔ реальные ID в context; честный picker | **S40** |
| 6. Токены / формулы UI | ERP поле, сумма/НДС | есть + **S34** |
| 7. Сохранить честно | кнопка пишет + sync КП | **S30** |
| 8. Не потерять | уход с confirm | **S38** |
| 9. Проверить | Просмотр = серверный HTML | **S31** |
| 10. Выдать | PDF / архив | есть |
| 11. Имя | rename | **S32** |
| 12. Шаблоны | save-as / picker delete | есть |
| 13. Правда | docs + smoke | **S36–S37** |
| 14. Гигиена кода | orphans | **S35** |

## Flexible binding (ответ на «любые данные с сайта»)

| Данные сайта | Как попадает в документ | Статус после FINISH+S40 |
|--------------|-------------------------|-------------------------|
| Наша фирма | JWT org → `{{organization.*}}` | OK |
| Клиент / плательщик / поставщик | Данные → anchors → `{{counterparty.*}}` / `{{anchor.payer.*}}` / `{{anchor.supplier.*}}` | OK после **S40** (сейчас payer токен врёт) |
| КП | select + lifecycle | OK |
| Заказ | select + table `order-items` + **`{{order.*}}`** | table OK; text token после **S40** |
| Каталог (много позиций) | витрина → table catalog-* | OK после **S27–S29** |
| Итоги таблицы | `{{table.subtotal\|vat\|grand}}` | OK |
| Договор / Счёт / одиночный product token | context ID + picker | **PARK** до NX UI этих модулей (BE частично умеет) |

**Гибкость =** выбрать сущность в «Данные» (или витрину) → вставить поле из picker → Preview/PDF подставляет.  
Не путать с «любой Mongo-коллекцией без binder» — это не гибкость, а пустые токены.
