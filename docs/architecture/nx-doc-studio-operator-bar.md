# Operator bar — что Cursor обещает по студии

> Я (Cursor) отвечаю за полноту **контура создания любых документов в NX `/studio`**.  
> Не за `/desk` MASTER-CORE и не за PARK (merge / Word / Excel-builder).

## Ментальная модель оператора

Чтобы **создать любой документ** и не стыдно показать коллеге, нужно:

| Шаг | Нужно | Покрытие |
|-----|--------|----------|
| 1. Начать | blank / из шаблона / дубль | list уже есть |
| 2. Тип документа | КП / договор / счёт / … | **S39** + shortcut КП **S33** |
| 3. Собрать лист | текст / таблица / фото / страницы | elements+layers — есть |
| 4. Подставить данные | клиент, якоря, **витрина товаров**, КП/заказ | **S27–S29** |
| 5. Токены / формулы | ERP поле, сумма/НДС | есть + **S34** |
| 6. Сохранить честно | кнопка пишет + sync КП | **S30** |
| 7. Не потерять | уход с confirm | **S38** |
| 8. Проверить | Просмотр = серверный HTML | **S31** |
| 9. Выдать | PDF / архив | есть |
| 10. Имя | rename | **S32** |
| 11. Шаблоны | save-as / picker delete | есть (S18/S19B) |
| 12. Правда | docs + smoke | **S36–S37** |
| 13. Гигиена кода | orphans | **S35** |

## Закрытие модуля
