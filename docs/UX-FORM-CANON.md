# UX form canon — validation without layout thrash

> Закон для агентов и людей. Нарушение = откат в review.

## Запрещено

- Всплывающий текст ошибки **под / над** полем, который **сдвигает** соседние поля, селекты, кнопки, карточки или сетку (`«Введите название»` выталкивает input вверх — классический антипример).
- Сообщения, которые появляются только после клика и меняют высоту ряда meta/toolbar без зарезервированного места.

## Канон (required fields)

1. **Красная рамка** (`border-destructive` / `aria-invalid="true"`) — основной сигнал.
2. Текст ошибки — только если **не двигает layout**:
   - `position` в зарезервированном слоте фиксированной высоты, **или**
   - `sr-only` / `aria-describedby` для a11y без визуального сдвига, **или**
   - toast / banner в footer (вне компактной строки полей).
3. `app-pi-form-field` `[error]` допустим, если слот ошибки уже учтён в вертикальном ритме (не прыгает соседний select).

## Диалоги / пикеры

- Клик «вставил» обязан дать **явную обратную связь** (toast / закрытие с понятным результатом). Тихая вставка без сигнала — баг.
