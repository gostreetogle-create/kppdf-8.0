## 6 зон сверху вниз (канон)

| # | Зона | Содержимое | Размер / примечание |
|---|------|------------|---------------------|
| 1 | **Шапка** | Бренд, «Сайт: Подключен», вкладки **Подключение · Импорт · ИИ** | ~46px; активная вкладка — gold underline |
| 2 | **Файл** | Имя, лист, N строк, вес; «Сменить лист / другой файл» | одна плашка, hairline |
| 3 | **Конфиг + маппинг** | Ряд селектов (сущность, профиль ★, заголовок, дубликаты) + сетка колонок A…F | контролы 28–32px |
| 4 | **Таблица** | Счётчики (всего/готово/⚠/✕) + preview; BOM: Lvl, Родитель | 11–13px в ячейках; фон таблицы `#ffffff` на `#fbf9f6` |
| 5 | **Inbox** (Desktop) | Путь к папке-капельнице, «Сканировать» | одна compact-строка |
| 6 | **Подвал** | Слева: идемпотентность/безопасность; справа: **одна** gold CTA с числом | ~44px, sticky, hairline-top |

Запрещено: hero-блоки, тени, 4-я вкладка, две gold-кнопки.

## Поле: Label → Value → Hint

| Слой | Правило |
|------|---------|
| **Label** | 11px, semibold, `#444748`, UPPERCASE, tracking ~0.03em, **margin-bottom 4px** |
| **Value** | 12–13px, `#1b1c1a`, padding **6×8px**, border **1px** `#c4c7c7`, **без shadow** |
| **Hint** | 10–11px, **3–4px** под value; gold `#904d00` (ИИ) или зелёный (ок); иконка контур **10×10** |

- Label **над** полем, не слева.
- Placeholder ≠ label.
- Ошибки пользователю — **по-русски** («В строке 14…»), не `unfit` / `exception`.

## Компактность без «тесноты»

- Внешний padding экрана: **16px**; между элементами: **8–12px** (не 32px «дырами»).
- Базовый UI: **13px**; таблица/мета: **11–12px**; заголовки блоков: **14px** max.
- Зоны разделять **hairline** `#c4c7c7`, не пустотой.
- Сетка **4/8px**; высота кнопок **30–32px**.
- Три уровня фона: экран `#fbf9f6` · плашка `#f3f1ee` · рабочая таблица `#ffffff`.
- **Framed content inset:** текст внутри блока с border/hairline (empty, loading, error) — **min 16px** от края (`--panel-content-inset` / `px-panel-inset`). Эталон controls: `px-control-x`. Anti-pattern: `padding: Xrem 0` на message в bordered box (см. `/desk` queue empty vs search). TZ: **DEN-505**.
- **Content column inset (shell):** под `app-pi-group-workspace` текст/контролы/доски **не** стартуют с x=0 колонки. `padding-inline: var(--panel-content-inset)` на `.group-body` (≥16px). `flushBody=true` (KP studio) — полный bleed без inset. TZ: **UX-443**.
- **Обрезанный текст в узкой колонке** → паттерн **`truncated-label-peek`** ([`ui-rules.md`](./ui-rules.md)): hover + раскрытие ▸, opaque плашка поверх сетки, без сдвига layout.

## Роли цвета (одна фраза)

| Цвет | Hex | Роль |
|------|-----|------|
| **Gold** | `#904d00` → hover `#fe932c` | **Единственная** залитая CTA, активная вкладка, ИИ-hint |
| **Teal / green** | `#0d9488` (канон) / `#1b6c37` (строка «Готово») | Подключено, успех, строка OK |
| **Amber** | `#7c5800` | Предупреждение («ШТУК → шт»), не блокер |
| **Red** | `#ba1a1a` | Блокирующая ошибка |

## Anti-patterns (топ-5)

1. **Тени / glass** — только hairline, формуляр на бумаге.
2. **Скругление > 4px** — почти прямоугольник (`rounded-sm`).
3. **#ffffff на весь экран** — только внутри таблицы/карточки.
4. **Несколько цветных кнопок** — gold заливка только у главной CTA.
5. **Залитые Material/emoji-иконки** — только Lucide 1.5px stroke.

## Чеклист «перед сдачей макета менеджеру»

- [ ] 3 вкладки: Подключение · Импорт · ИИ
- [ ] Палитра: фон `#fbf9f6`, текст `#1b1c1a`, hairline `#c4c7c7`, CTA `#904d00`
- [ ] `box-shadow: none` на панелях и таблицах
- [ ] Русский UI, без `unfit` / `exception` / `null`
- [ ] Одна золотая CTA («Отправить **N** строк…»)
- [ ] BOM: Lvl + Родитель видны (если спецификация)
- [ ] Кегль: 11 / 12 / 13 / 14 px по иерархии
- [ ] В футере — защита от задвоения (идемпотентность)
