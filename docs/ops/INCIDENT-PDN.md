# Реагирование на инцидент с персональными данными (kppdf)

> **Черновик ops.** Не юридическая консультация. Согласовать с юристом до первого инцидента.
> Сроки по 152-ФЗ ст. 21 (ред. 2025): **24 часа** — первичное уведомление РКН;
> **72 часа** — уточняющий отчёт (если применимо).

## 1. Что считать инцидентом

- Несанкционированный доступ к Mongo, `uploads/`, бэкапам.
- Утечка учётных данных admin / JWT / device cookie в открытый канал.
- Отправка ПДn во **foreign SaaS** (Sentry, почта, AI) без разрешения.
- Публикация КП/договора с контактами клиента **в открытый** интернет по ошибке.
- Ransomware / wipe prod без восстановления из backup.

## 2. Немедленно (0–2 ч)

1. **STOP** дальнейшей утечки: отозвать compromised tokens, сменить `ADMIN_PASSWORD`, отключить скомпрометированные device grants (`/admin/devices`).
2. Сохранить **доказательства**: время, IP, docker logs, nginx logs, audit tail (не выгружать лишние ПДn в чаты).
3. Сообщить **ответственному за ПДn** и PO.
4. Не удалять логи «чтобы не было следов» — это ухудшает позицию.

## 3. 24 часа — уведомление Роскомнадзора

- Если инцидент = **неправомерная или случайная** передача/доступ к ПДn, **повлекшая нарушение прав** субъектов.
- Канал: официальный порядок РКН (личный кабинет / форма на pd.rkn.gov.ru — уточняет юрист).
- Штраф за **неуведомление**: ч. 11 ст. 13.11 КоАП — **1–3 млн ₽** (ЮЛ), отдельно от санкций за утечку.

## 4. 72 часа — отчёт

- Состав данных, число субъектов (оценка), меры, контакты, статус уведомления субъектов (если требуется).
