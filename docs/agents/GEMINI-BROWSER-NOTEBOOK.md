# Gemini в браузере ↔ kppdf (без локального API)

> Для PO. Не путать с корневым `GEMINI.md` — это контракт **локального** агента-исполнителя в репо (как Freebuff/Claude CLI).  
> Здесь — **gemini.google.com** → «Блокноты», только браузер, без ключей API в наш backend.

updated_at: 2026-09-06

## 1. Что такое «Блокноты»

Папка проекта внутри Gemini: свои чаты + **источники** (файлы/PDF/MD/Drive/URL/вставленный текст) + опционально инструкции блокнота.  
Ответы опираются на загруженные источники (+ обычные возможности Gemini в этом чате). Синхронизируется с NotebookLM у подписчиков Google AI.

Твой блокнот **«Архитектор kppdf (Nx Migration)»** — правильное место для архитектурных/паттерн-разговоров.

**Чего нет:** доступа к `D:\kppdf-8.0`, git, `pnpm`, Mongo, NX `:4201`. Он не claim'ит TZ и не коммитит.

## 2. Как задействовать без API

Конвейер **через тебя** (HITL), как Desktop pairing:

```
Cursor (я) → пишу промпт / выжимку файлов
     ↓ ты копируешь
Gemini Notebook (источники + чат)
     ↓ ты копируешь ответ / сохраняешь .md
Cursor / Freebuff / Claude → используют как вход для TZ или кода
```

### Что класть в источники блокнота (рекомендуемый минимум)

Не весь репо. Короткие каноны (экспорт/копия текста):

| Источник | Зачем |
|----------|--------|
| `docs/PO-CANON.md` | характер продукта |
| `docs/CONTEXT.md` | словарь (КП ≠ Organization) |
| `docs/architecture/MASTER-CORE.md` (или кусок) | север |
| релевантный `docs/pages/*.page.md` | экран |
| 1–3 файла кода / кусок TZ | конкретный вопрос |

Лимиты источников зависят от тарифа Google AI (Plus/Pro/Ultra). Большие `.ts` режь до сути.

### Инструкция блокнота (пример, вставить в settings notebook)

```text
Ты peer-архитектор для цехового ERP kppdf (Angular NX + Nest).
Отвечай по-русски, коротко. Не выдумывай API/сущности вне источников.
Клиент = Counterparty. КП = Quotation (в UI «КП»).
Не предлагай второй write-path. Результат: варианты + риски + псевдокод/паттерн, не полный PR.
```

## 3. Когда звать Gemini (а когда нет)

| Задача | Кто |
|--------|-----|
| Исполнить TZ, claim, gates, commit | Freebuff / Claude CLI / локальный Gemini CLI (`GEMINI.md`) |
| Идея UX, сверка с каноном, паттерн Angular, альтернатива до TZ | **Блокнот Gemini** (я даю промпт → ты кидаешь → ответ сюда или в `docs/peer/`) |
| Сложный баг с живым деревом файлов | Claude CLI / Cursor — у них диск |

## 4. Куда складывать ответы

Предпочтительно: `docs/peer/gemini-YYYY-MM-DD-<тема>.md` (короткая выжимка + ссылка «из блокнота»).  
Cursor читает и при необходимости делает TZ. Не коммитить секреты/пароли.

## 5. Связь с потоками

Gemini **не** третий executor-слот в `STREAM-QUEUE`. Это **peer-мозг**.  
Если ответ Gemini стал задачей на код — Cursor кладёт TZ в Freebuff или Claude stream.
