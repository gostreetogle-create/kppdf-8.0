## Implementation (6 file ops)

### 1. NEW — `frontend/src/app/shared/services/doc-types.service.ts`

Hand-written `DocTypesService` mirroring `OrganizationsService` canonical 5-CRUD shape (list/findById/create/update/remove). `list()` synthesizes a `{items, total, page, limit}` envelope from the backend flat-array response via `silentGet<DocType[]>(...).pipe(map(...))`.

```ts
list(): Observable<SilentResult<DocTypesListResponse>> {
  return silentGet<DocType[]>(this.http, `${this.baseUrl}/doc-types`).pipe(
    map((res) => {
      if (!res.ok) return res;
      const arr = res.data ?? [];
      return { ok: true as const, data: { items: arr, total: arr.length, page: 1, limit: Math.max(arr.length, 1) } };
    }),
  );
}
```

### 2. NEW — `frontend/src/app/shared/services/doc-types.service.spec.ts`

4 unit tests via HttpTestingController:
- list() wraps 3-element flat array into `{items: 3, total: 3, page: 1, limit: 3}` envelope
- list() returns `ok:false` on backend 500
- create() POSTs name + slug body
- remove() DELETEs `/api/doc-types/:id`

### 3. MODIFIED — `frontend/src/app/shared/services/pi-document-templates.service.ts`

Added 2 new typed methods following the existing `silentPost` wrapper pattern:

- `setDefault(id: string): Observable<SilentResult<void>>` — `POST /document-templates/:id/set-default`
- `duplicate(id: string): Observable<SilentResult<DocumentTemplate>>` — `POST /document-templates/:id/duplicate`

Both log audit rows (admin/manager roles only) via the existing controller-level `@AuditAction` decorator.

### 4. MODIFIED — `frontend/src/app/shared/services/pi-document-templates.service.spec.ts`

Added 2 unit tests:
- `setDefault()` POSTs to `/:id/set-default` with empty body
- `duplicate()` POSTs to `/:id/duplicate` and returns the new template record (isActive=false, isDefault=false)

### 5. REWRITE — `frontend/src/app/pages/doc-constructor/templates/templates.page.ts`

Removed:
- `import { HttpClient } from '@angular/common/http';`
- `import { API_BASE_URL } from '../../../core/api.tokens';`
- `private readonly http = inject(HttpClient);`
- `private readonly baseUrl = inject(API_BASE_URL);`
- All 5 `// eslint-disable-next-line @pi-dsl/no-raw-http-in-components ...` annotations

Added:
- `import { OrganizationsService } from '.../organizations.service';`
- `import { DocTypesService } from '.../doc-types.service';`
- `private readonly orgSvc = inject(OrganizationsService);`
- `private readonly docTypeSvc = inject(DocTypesService);`

`createWithSettings` refactored from nested-subscribe to flat `forkJoin({orgs, docTypes}).pipe(switchMap, switchMap, takeUntilDestroyed)` pipeline. Per-entity auto-create uses inline `map((res) => { if (!res.ok) throw res.error; return res.data._id; })` so failures propagate via outer error handler with `extractErrorMessage(err)` toast (more specific than the previous generic "Ошибка создания сущностей").

`onSetDefault` and `onDuplicate` rewritten as 1-line `.subscribe({next, error})` against typed service methods. Both retain defensive `error:` handlers per project convention.

### 6. REWRITE — `frontend/src/app/pages/doc-constructor/templates/templates.page.spec.ts`

Removed:
- `provideHttpClient` / `provideHttpClientTesting` / `HttpTestingController` (page no longer uses raw HTTP)

- `DocTypesService` mock with synthetic `{items: [{_id, name, slug, isActive}], total: 1, page: 1, limit: 1}` response
- `setDefault` + `duplicate` methods on the `DocumentTemplatesService` mock

Kept the same 5 behavioral test cases (component instantiation, items render post-load, loading=false after sync list, search filter, clear-search restoration) — all PASS.
