## 1. Архитектурное решение

### ШАГ 1: Dependabot setup

`.github/dependabot.yml`:
- Backend: `pnpm audit` weekly; PR policy: `version-bump-patch` для low, `version-bump-minor` для moderate, separate triage для high/critical.
- Frontend: same.
- Repo-level secrets scan: `github/codeql-action` или аналог.

### ШАГ 2: CI check script

`scripts/nightly-dep-check.sh` (NEW):
- `pnpm audit --prod --json | jq '.vulnerabilities | map(select(.severity=="high" or .severity=="critical")) | length'`
- If > 0 → exit 1.
- Запускать в nightly scheduled workflow (если нет CI — оставить скрипт готовым).

### ШАГ 3: HTTPS enforcement

`backend/src/main.ts`:
- Production: `app.use((req, res, next) => { if (!req.secure && req.headers['x-forwarded-proto'] !== 'https') return res.redirect(301, ...); next() })` ТОЛЬКО если `TRUST_PROXY=1`.
- Dev: не enforce.

### ШАГ 4: Body-size alignment

`backend/src/main.ts`:
- `app.use(json({limit: '1mb'}))` — для routes кроме upload-flows которым явно больший лимит.
- `app.use(urlencoded({extended: true, limit: '1mb'}))`.
- Upload routes — собственный multer с per-feature ограничениями (TZ-250).

### ШАГ 5: Trusted proxy headers

`backend/src/main.ts` (TZ-249):
- Если `TRUST_PROXY=1` → `app.set('trust proxy', 1)` → X-Forwarded-For accepted (одного hop).
- Иначе — IP from `req.socket.remoteAddress` используется.

### ШАГ 6: MongoDB exposure check

`docker-compose.yml`:
- MongoDB service — НЕ expose `0.0.0.0:27017`; bind на `127.0.0.1:27017` только.
- Production deploy — отдельный compose overrides (`docker-compose.prod.yml`) — verify.
- Если из текущего compose Mongo опубликована наружу — зафиксировать как `OPERATIONAL ACTION REQUIRED`.

### ШАГ 7: Runbook

`docs/runbook/operational-checklist.md` (NEW):
- Production pre-deploy checklist:
  - JWT secrets rotated, ≥32 chars
  - ADMIN_PASSWORD ≥8 chars strong
  - HTTPS terminator configured
  - Mongo не публична
- Periodic review:
  - Dep advisories check (nightly)
  - User audit log review (weekly — admin activity)
  - Backup verify (monthly — operationally)
- Раздел "OPERATIONAL ACTION REQUIRED" — только для вещей, которые manual.

### ШАГ 8: Secrets exclusion

Все `.env`, `.env.local`, `*.key`, `*.pem` уже в `.gitignore`. Verify; mark any one-off.

### ШАГ 9: Lint baseline

`pnpm lint` runs в CI; failing блокирует merge (existing TZ-44, TZ-46).

### ШАГ 10: Body-size test

- POST с body 1.5MB → 413 на json endpoint.
- POST с body 10MB (oversize upload) → 415 на file bucket (TZ-250).
