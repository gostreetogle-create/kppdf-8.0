## Implementation (5 surgical edits + 1 cleanup)

### Edit 1 — Imports (line 12): remove `HttpClient`

```diff
- import { HttpClient, HttpErrorResponse, httpResource } from '@angular/common/http';
+ import { HttpErrorResponse, httpResource } from '@angular/common/http';
```

`httpResource` is NOT banned by Rule 1 — only `this.http.<verb>(...)` is. `HttpErrorResponse` is a TypeScript type (not the HttpClient instance) — also legitimate for `error:` handlers.

### Edit 5 — `onCreateTemplate`: lookup auto-fetch through typed services

```diff

-   `${this.baseUrl}/organizations?limit=1`,

-       const orgId = orgRes?.items?.[0]?._id;
-       const docTypeId = dtRes?.[0]?._id;
+     next: (results) => {
+       const orgs = results.orgs;
+       const docTypes = results.docTypes;
+       const orgId =
+         orgs.ok && orgs.data.items.length > 0 ? orgs.data.items[0]._id : undefined;
```
