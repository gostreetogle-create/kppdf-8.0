# TZ-210 — Design Audit: Logomock → kppdf-8.0 Integration

**Статус:** 📋 Новое
**Приоритет:** Высокий
**Зона:** Frontend (`frontend/src/styles.css`, глобальные токены)

---

## 1. Контекст

Пользователь получил дизайн-макет из Logomock (React + Tailwind) в ZIP-архиве (`для формирования дизайна/logomock.zip`). Задача — **взять лучшие визуальные элементы** из макета и **внедрить в существующий Angular-проект** без переписывания и ломания текущей архитектуры.

**Ключевой принцип:** Это АУДИТ и ТОЧЕЧНАЯ ИНТЕГРАЦИЯ, не полная переработка. Проект kppdf-8.0已有 значительные инвестиции (Paper & Ink, OKLCH, hairline-first, Tailwind v4). Мы БЕРЁМ визуальные решения из макета, но ПРИМЕНЯЕМ их через нашу архитектуру.

---

## 3. Принципы интеграции

1. **НЕ трогаем light mode палитру** — Paper & Ink бренд сохраняется. Изменения только в dark mode + добавления.
2. **Hex → OKLCH** — конвертируем hex из макета в OKLCH для консистентности с текущей архитектурой.
3. **Добавляем, не заменяем** — новые токены (`paper-3`, `paper-4`, `success`, `info`, `warning`) добавляются, существующие обновляются точечно.
4. **Компоненты не переписываем** — только глобальные CSS-токены и utility-классы в `styles.css`.
5. **Обратная совместимость** — все существующие классы (`hairline`, `pi-input`, `pi-cell`, etc.) продолжают работать.

## 5. Acceptance Criteria

- [ ] Dark mode использует 4-уровневую иерархию: `paper` → `paper-2` → `paper-3` → `paper-4`
- [ ] Gold accent в dark mode = `#E2B842` (ярче текущего `#D4AF37`)
- [ ] Текст в dark mode = `#F0F4F8` (нейтральный, лучший контраст)
- [ ] Добавлены `success`, `info`, `warning` + soft-варианты в обе темы
- [ ] `executive-shadow` доступен как utility-класс
- [ ] Плавный переход между темами (0.2s ease на body)
- [ ] Кастомный тонкий scrollbar (6px) в обеих темах
- [ ] `* { border-color: var(--color-rule) }` глобально
- [ ] `eyebrow` letter-spacing = `0.08em`
- [ ] Все существующие компоненты работают без изменений
- [ ] WCAG AA контраст сохраняется
