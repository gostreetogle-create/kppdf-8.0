# QA-445G: Desktop → Импорт — нет категории «Снабжение» в Excel-формах

РОЛЬ: desktop (Tauri/Svelte, `desktop/src/**`) + backend, если список
категорий/таблиц приходит с сервера, а не захардкожен в desktop-клиенте.

CONFLICT KEYS: `desktop/src/**` (вкладка «Импорт» KPPDF Desktop),
серверный список экспортируемых Excel-форм/категорий, если он не локальный.

ЧТО: На вкладке «Импорт» приложения KPPDF Desktop есть выпадающий список
«Категория» → «Таблица» для скачивания Excel-формы (шпаргалка: скачать форму
→ заполнить лист «Данные» → загрузить обратно). PO обвёл этот блок и
написал «Таблицы не все! — снабжение нужно» (16:55) — то есть в списке
категорий сейчас нет (или неполный) раздел «Снабжение», а он нужен для
импорта данных снабжения через эту же Excel-форму механику.

Первый шаг — найти, где в коде задан список категорий/таблиц для Excel-форм
(десктоп клиент или API), понять, почему «Снабжение» отсутствует (не
реализовано вообще / реализовано, но не выведено в этот селектор), прежде
чем писать новый экспорт с нуля.

НЕ: не трогать вкладки «Подключение»/«ИИ» этого приложения — только раздел
«Импорт» → список категорий форм.

AC: в выпадающем списке «Категория» на вкладке «Импорт» доступна категория
«Снабжение» с соответствующими таблицами; скачанная форма и обратная
загрузка проходят по той же механике, что и остальные категории (шаблон →
заполнение листа «Данные» → загрузка → сопоставление колонок).
