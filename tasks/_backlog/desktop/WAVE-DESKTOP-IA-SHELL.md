## Три двери (канон UI)

| Tab id | Подпись RU | Содержимое |
|--------|------------|------------|
| `connection` | **Подключение** | Только паринг, статус пользователя, отвязать. Чип «Подключено: …» в шапке можно оставить. |
| `import` | **Импорт** | Формы Excel + drop/файл + маппинг + inbox (ручной путь) + отправка/отчёт. Главная вкладка по умолчанию. |
| `ai` | **AI** | Два блока на одном экране: **Локальная модель** | **MCP (агенты)**. Короткие hint: импорт работает и без модели/MCP. |

Убрать вкладки с именами «MCP» / «Модель» / «Студия импорта» как отдельных top-level.
