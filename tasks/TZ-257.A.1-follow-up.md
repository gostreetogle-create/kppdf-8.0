### 1. Close the LastAdminGuard demotion gap

Files:

- `backend/src/common/guards/last-admin.guard.ts`
- `backend/src/common/guards/last-admin.guard.spec.ts`

Add unit coverage for:

- demoting the only active admin → rejected;
- demoting an active admin while another active admin exists → allowed.

### 2. Add administrator password reset

Create:

- `backend/src/modules/admin/dto/admin-reset-password.dto.ts`

The DTO has only `newPassword`, validated as a string of length 8–128. It must not require `oldPassword`.

Add to `backend/src/modules/user/user.service.ts`:

- `adminResetPassword(id, newPassword)`;
- load the target user;
- bcrypt-hash the new password;
- increment `refreshTokenVersion`;
- save and invalidate `userActivityCache`;
- do not compare the old password.

Add to `backend/src/modules/admin/users-admin.controller.ts`:

- `POST /api/admin/users/:id/reset-password`;
- `@Permissions('user:admin')` and `@Roles('admin')`;
- `@UseGuards(LastAdminGuard)`;
- `@AuditAction({ action: 'admin.user.password-changed', entityType: 'User', idParam: 'id' })`;
- return `toClientUser()`.
