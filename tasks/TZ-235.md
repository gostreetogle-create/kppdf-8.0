## 0. TL;DR для PO

**Цель:** сделать Конструктор шаблонов уровня лучших мировых аналогов (ReportBro + invoice-template-creator), **но с нашим главным преимуществом** — полная интеграция с нашей MongoDB. Любые данные из любых коллекций подставляются прямо в шаблон. Это то, чего нет ни у ReportBro (только статический JSON dataset), ни у invoice-template-creator (только хардкод-значения).

**Что НЕ делаем:**  
- ❌ НЕ копируем код ReportBro. License у них — AGPLv3 / Commercial — НЕ совместима с нашим proprietary. Берём только **UX-паттерны и идеи**, реализуем с нуля на Angular CDK + наш DSL.
- ❌ НЕ остаёмся на god-component в 1790 строк. Прежде чем добавлять фичи — развязываем в сервис + детальки-DSL.

**Главная гипотеза:** микс трёх источников даёт Конструктор лучше, чем каждый по отдельности:  
- **ReportBro** → плавность drag, snap-визуализация, undo/redo, tables с auto-fill, placeholders `{{...}}`, smart alignment guides  
- **invoice-template-creator** → 4-panel layout (Tools | Canvas | Page Settings | Layers), современные micro-interactions, clean иконки  
- **Наши идеи + DSL** → реальная backend data binding, Group Drag, прозрачный PNG overlay, multi-select alignment

**Скоуп:** ~280–350 h, 5-7 месяцев при 2-3 сессиях в неделю (по 3-4 ч каждая).

### TZ-235.C — Undo/Redo (state-based history)

**Файл:** NEW: `frontend/src/app/pages/doc-constructor/builder/history.service.ts`

**Что делаем:**  
- Command-based history с двумя stacks: undoStack, redoStack.  
- Operations: ADD_BLOCK, REMOVE_BLOCK, UPDATE_BLOCK, REORDER_BLOCKS, UPDATE_TEMPLATE, MULTI_OP.  
- Snapshot blocks[] до изменения → push в undoStack. После zmiany → clear redoStack.  
- Debounce 300ms на каждое изменение (collapses серию drag-moves в одну op).  
- Circular buffer: max 50 entries (LRU eviction при превышении).  
- Keyboard: Ctrl+Z → undo, Ctrl+Shift+Z → redo.

**Acceptance:**  
- Unit test: выполнить 20 ops → 20 undo → state identical к starting state  
- Keyboard: Ctrl+Z / Ctrl+Shift+Z работают в builder (focused window)  
- Memory: max 50 entries, не больше  
- Visual QA: undo перерисовывает canvas identically

**Effort:** 8-10 h. **Зависит от:** TZ-235.A.

## 7. Backend dependencies (cross-batch)

⚠️ Следующие TZ на backend НЕ существуют — нужны до старта соответствующих frontend sub-TZ:

### TZ-237: Backend PDF render service
- Endpoint: `POST /api/templates/:id/preview` → returns `application/pdf` binary
- Внутри: NestJS service использует либо `pdfmake` / `puppeteer` / собственный DOM-to-PDF рендер
- Latency target: < 1.5s для типичного template
- Кеширование: hash(template payload) → cached PDF на 60s

**Когда делать:** до TZ-235.F (Wave 6). Effort: 16-20 h.

### TZ-236: Backend datasets store
- Collections: `datasets` (MongoDB schema): `_id, name, schemaJson, sampleDataJson, createdAt, updatedAt`
- Endpoints: `CRUD /api/datasets` (через defineEntity в NestJS)
- Validation: sampleData matches schema (Zod / Joi)
- Кеширование in-memory datasets (TTL 5 min)

**Когда делать:** до TZ-235.E (Wave 5). Effort: 10-14 h.

### TZ-238: Backend bulk update endpoint
- Endpoint: `PATCH /api/template-blocks/bulk` (atomic bulkWrite Mongo)
- Body: `{ operations: [{_id, patch}, ...] }`
- Все ops в ОДНОЙ Mongo transaction — либо все apply, либо все rollback
- Latency: < 200ms для batch до 50 ops

**Когда делать:** до TZ-235.D (Wave 3). Effort: 8-10 h.

**Total backend dependency effort:** 34-44 h (в дополнение к frontend 138-176 h).

## 9. Risks & Pitfalls

| Риск | Severity | Mitigation |
|------|----------|-----------|
| Live PDF preview медленный (>1.5s) | HIGH | debounce 500ms; backend CDN; предкомпиляция templates |
| Undo/redo state explosion 100+ ops | MED | circular buffer 50; только STRUCTURAL changes (НЕ pixel-level) |
| Group drag с auto-save flood backend | HIGH | debounce save 1.5s; bulk PATCH (TZ-238 dependency) |
| Placeholders с circular JSON ref | MED | Zod validation at save-time НЕ runtime |
| Все 16 sub-TZ одновременно = chaos | HIGH | строгая последовательность по Wave 1-7; каждая = closed commit + visual snapshot |
| 1790-строк god-component при рефакторе | MED | Wave 1 (TZ-235.A) изолирует ДО других фич |
| GPU-ускорение не работает в Firefox/older browsers | LOW | feature detect + graceful fallback to non-GPU |
| 4-panel layout breaks mobile/tablet | MED | responsive test обязателен в TZ-235.L |
