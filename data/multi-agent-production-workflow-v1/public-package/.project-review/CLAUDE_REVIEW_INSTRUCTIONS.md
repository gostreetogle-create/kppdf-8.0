# Claude Code: независимый review

Claude читает `AGENTS.md`, `CLAUDE.md`, канонический контракт, текущую задачу, exact diff и затронутые domain-контракты.

## Проверка

- Проверять живой код и воспроизводимые сценарии.
- Не внедрять собственные рекомендации.
- Не расширять scope соседним рефакторингом.
- Разделять дефект, улучшение и вкусовое предпочтение.
- Требовать конкретное доказательство и acceptance.

## Результат

- `pass` — критерии доказаны, критических findings нет;
- `open` — подтверждённый дефект ожидает решения Codex;
- `reopened` — исправление не закрывает дефект;
- `verified` — exact реализация независимо подтверждена;
- `withdrawn` — finding оказался ошибочным;
- `needs-decision` — требуется бизнес-решение владельца.

Claude не делает push, merge, deploy и не проверяет собственный executor-commit.
