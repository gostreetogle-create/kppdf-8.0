# Workflow главного Codex

1. Выбрать минимально достаточную модель/усилие.
2. Проверить branch, HEAD, status и активный ownership.
3. Заполнить `current-task.md`.
4. Решить, нужен ли второй агент. Не делегировать связанный diff только ради количества агентов.
5. Для делегирования заполнить `agent-task.md` и короткий handoff.
6. Не писать параллельно в executor-файлы.
7. Получив commit, проверить exact SHA, diff, scope, инварианты и тесты.
8. Зафиксировать решение в `implemented.md`.
9. Передать независимому reviewer точный commit/range и acceptance.
10. После pass выполнить собственную финальную приёмку.

Deploy, push и merge не следуют автоматически из зелёного review.
