# Zcode: ограниченная локальная реализация

Zcode работает по той же модели bounded executor:

1. Получает exact handoff и marker `agent: zcode`.
2. Проверяет branch, baseline и отсутствие пересечения.
3. Меняет только exact allowed paths.
4. Выполняет указанные проверки.
5. Создаёт один локальный commit `zcode: ...`.
6. Передаёт SHA Codex и прекращает работу.

Если конкретный клиент Zcode не поддерживает технический hook, ограничения остаются обязательным процессным контрактом. Codex должен проверять их по diff и Git history.
