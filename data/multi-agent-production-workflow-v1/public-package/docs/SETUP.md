# Настройка шаблона

## 1. Скопируйте файлы

Поместите содержимое архива в корень репозитория. Не перезаписывайте действующие правила без ручного сравнения.

## 2. Адаптируйте проект

- замените `<PROJECT_ROOT>`;
- опишите защищённые домены и production boundary;
- укажите локальные test/smoke-команды;
- настройте branch prefixes;
- проверьте, какие thread/message tools реально доступны;
- заполните точные пути Python в `.claude/settings.example.json`.

## 3. Активируйте Project Review

Скопируйте шаблоны из `.project-review/templates/` на уровень `.project-review/` и уберите суффикс шаблона. Одновременно держите только одну активную задачу.

## 4. Настройте Claude hooks

Переименуйте `.claude/settings.example.json` в `.claude/settings.json` после ручной проверки. Hook fail-closed блокирует запись вне reviewer-файлов или exact `allowed_paths` активного marker.

Сначала протестируйте hooks в отдельной учебной ветке:

- reviewer может записать рекомендацию;
- reviewer не может изменить runtime;
- executor может изменить только declared path;
- dangerous Bash блокируется;
- синтаксическая ошибка Python возвращается агенту.

## 5. Подключите навыки

Скопируйте папки из `skills/` в каталог навыков Codex либо оставьте их как project-local инструкции, если клиент поддерживает локальные skills.

## 6. Первый безопасный прогон

Возьмите маленькую обратимую задачу без БД и production. Пройдите полный цикл: handoff, отдельный commit, независимый review, verification и финальную приёмку.
