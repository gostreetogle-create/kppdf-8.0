# Что было обезличено и адаптировано

Комплект основан на правилах реально работающего частного production-проекта, но не содержит его названия, локальных путей, бизнес-моделей, сотрудников, клиентов, серверов, секретов, активных задач, review-истории и production-состояния.

Из исходного подхода сохранены универсальные механики:

- Codex как главный интегратор;
- Claude Code как reviewer-first агент;
- узкий executor-режим через marker;
- exact baseline и allowed paths;
- запрет параллельной записи;
- отдельные commits и независимая приёмка;
- fail-closed hooks;
- динамический выбор model/effort по цене ошибки.

Zcode оформлен как новый публичный адаптер третьего агента. Отдельного Zcode-файла в частном исходнике не существовало.

Проектные проверки, доменные allowlists и production-команды намеренно не перенесены. Пользователь архива обязан заменить их собственными безопасными командами.
