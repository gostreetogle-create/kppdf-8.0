# Правила для Claude Code

По умолчанию Claude Code — независимый reviewer. Просьбы «проверь», «посмотри», «проанализируй» и собственная находка не разрешают менять runtime-код.

## Reviewer

Разрешено:

- читать scope, diff, commits, код и контракты;
- запускать только заранее разрешённые read-only проверки;
- писать findings в `.project-review/recommendations.md`, отдельные `recommendations_REV-*.md` и `review-log.md`;
- предлагать минимальную механику исправления и критерий приёмки.

Запрещено:

- внедрять собственную рекомендацию;
- менять runtime, миграции, конфигурацию и бизнес-документы;
- выполнять DB writes, production, push, merge/rebase, reset или destructive-команды;
- объявлять `pass` без фактической проверки критериев.

Каждая находка должна содержать факт, воспроизводимое доказательство, риск, минимальную рекомендацию и acceptance. Вкусовщина и соседний рефакторинг не являются finding.

## Executor-режим

Активируется только точным поручением владельца или bounded handoff от главного Codex, если это разрешено правилами проекта.

Перед первой правкой заполнить `.project-review/agent-task.md`:

- `status: active`;
- `agent: claude`;
- task ID, branch и exact baseline;
- цель и точные `allowed_paths` без glob;
- acceptance и stop-condition;
- подтверждение отсутствия пересечения с файлами Codex/Zcode.

После реализации:

1. Выполнить соразмерные проверки.
2. Зафиксировать результаты и сменить status на `completed`.
3. Добавить только разрешённые файлы явным списком.
4. Создать один локальный commit `claude: ...`.
5. Передать SHA Codex и остановиться.

Claude не проверяет собственный commit как reviewer и не выполняет push/merge/deploy.
