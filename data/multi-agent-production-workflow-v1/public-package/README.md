# Совместная работа Codex + Claude Code + Zcode

Публичный обезличенный шаблон для сложных программных продуктов, где один AI-агент реализует и интегрирует изменения, второй независимо проверяет, а третий получает только ограниченные самостоятельные участки.

## Что решает комплект

- не даёт нескольким агентам одновременно переписывать одни файлы;
- отделяет реализацию от независимой приёмки;
- фиксирует границы задачи, baseline, разрешённые файлы и критерии готовности;
- запрещает production, push, merge и destructive-действия без отдельного решения владельца;
- заставляет каждую рекомендацию подтверждать кодом, diff, тестом или другим проверяемым доказательством;
- выбирает минимально достаточную модель и глубину рассуждения, чтобы не расходовать дорогие токены на механическую работу.

## Роли

1. **Владелец продукта** определяет бизнес-смысл, критические границы и отдельно разрешает production.
2. **Codex** — главный архитектор, исполнитель и интегратор. Он владеет итоговым решением и финальной приёмкой.
3. **Claude Code** — независимый reviewer по умолчанию. Исполнителем становится только после точного поручения и заполненного task-marker.
4. **Zcode** — дополнительный ограниченный агент. Получает отдельный непересекающийся scope, собственную ветку/worktree и передаёт commit Codex.

Zcode-адаптер создан как публичный шаблон по той же модели безопасности. В исходном проекте отдельного файла `ZCODE.md` не было.

## Быстрый запуск

1. Скопируйте `AGENTS.md`, `CLAUDE.md`, `ZCODE.md`, `.project-review/` и `.claude/` в корень своего репозитория.
2. Замените плейсхолдеры `<PROJECT_ROOT>`, `<LOCAL_TEST_COMMAND>` и перечень защищённых зон.
3. Создайте рабочие файлы из `.project-review/templates/`.
4. Оставьте Claude reviewer по умолчанию. Для реализации выдавайте точный marker с `allowed_paths` без glob.
5. Не передавайте двум агентам одни и те же файлы одновременно.

Подробная настройка: [docs/SETUP.md](docs/SETUP.md).

## Ключевой цикл

`Задача → ограниченный diff → commit → независимый review → исправление → verification → финальная приёмка Codex → отдельное решение о deploy`

## Важное ограничение

Прямой обмен сообщениями между Windows-приложениями зависит от доступных инструментов конкретной платформы. Если есть same-task/thread messaging, используйте структурированный handoff. Если его нет — передавайте тот же handoff вручную. Никогда не имитируйте успешную доставку или подтверждение модели.

Этот комплект — стартовый шаблон. Он не заменяет правила вашего домена, тесты, резервные копии, rollback и человеческое решение для необратимых действий.
