# Fix: Text Blocks Editing Bugs

## Проблемы

### Bug 1: На странице текстовых блоков нажатие "Редактировать" ничего не делает

**Root cause:** `TextBlockEditorComponent` (text-block-editor.component.ts:590-611) инициализирует форму в **конструкторе** читая `this.block()`. Но в Angular сигнал-инпуты (`input<T>()`) устанавливаются ПОСЛЕ конструктора. Когда `openEdit(row)` вызывается, `editingBlock()` меняется → Angular создаёт `TextBlockEditorComponent` → конструктор видит `this.block() === null` → форма не заполняется.

**Evidence:**
- text-block-editor.component.ts:541 — `readonly block = input<TextBlock | null>(null)`
- text-block-editor.component.ts:590-611 — constructor читает `this.block()`
- Signal inputs are set AFTER constructor → `this.block()` is always `null` in constructor

### Bug 2: Из конструктора документов "Редактировать" перекидывает на texts без открытия

**Root cause:** builder.page.ts:1276-1292 — `onEditSelected()` делает `this.router.navigate(['/doc-constructor/texts'])` без передачи ID блока. Текстовый блок ID хранится в `block.dataBinding.value` (см. builder.page.ts:1219-1222).

## План исправлений

### Step 1: Fix TextBlockEditorComponent — constructor → effect

**File:** `frontend/src/app/pages/doc-constructor/texts/text-block-editor.component.ts`

Заменить constructor-based init (строки 590-611) на `effect()`:

```typescript
constructor() {
  // Empty — init moved to effect
}

private readonly initEffect = effect(() => {
  const existing = this.block();
  if (!existing) {
    if (this.columns().length === 0) {
      this.columns.set([this.makeColumn()]);
    }
    return;
  }
  this.nameControl.setValue(existing.name);
  this.activeControl.setValue(existing.isActive);
  if (existing.columns && existing.columns.length > 0) {
    this.columns.set(
      existing.columns.map((c) => ({
        id: c.id || crypto.randomUUID(),
        content: c.content || '',
        width: c.width ?? 1,
      })),
    );
    this.columnsCount.set(existing.columns.length);
  } else {
    this.columns.set([{ id: crypto.randomUUID(), content: existing.content || '', width: 1 }]);
    this.columnsCount.set(1);
  }
  this.activeColIndex.set(0);
});
```

### Step 2: Fix Builder — pass textBlockId via query params

**File:** `frontend/src/app/pages/doc-constructor/builder/builder.page.ts`

Изменить `onEditSelected()` (строки 1280-1284):

```typescript
case 'text': {
  // Text block ID is stored in dataBinding.value (set at builder.page.ts:1221)
  const textBlockId = block.dataBinding?.value;
  if (textBlockId) {
    this.router.navigate(['/doc-constructor/texts'], {
      queryParams: { editId: textBlockId },
    });
  } else {
    // Fallback: navigate without editId
    this.router.navigate(['/doc-constructor/texts']);
  }
  break;
}
```

### Step 3: Fix TextsPage — read query param and auto-open editor

**File:** `frontend/src/app/pages/doc-constructor/texts/texts.page.ts`

1. Добавить `ActivatedRoute` injection
2. В constructor подписаться на `queryParams.editId`
3. Если `editId` есть — загрузить блок и вызвать `openEdit`

```typescript
import { ActivatedRoute } from '@angular/router';
import { map, filter } from 'rxjs';

// В class body:
private readonly route = inject(ActivatedRoute);

// В constructor, после this.reload():
this.route.queryParams
  .pipe(
    map((p) => p['editId'] as string | undefined),
    filter((id): id is string => !!id),
    switchMap((id) => this.service.findById(id)),
    takeUntilDestroyed(this.destroyRef),
  )
  .subscribe((res) => {
    if (res.ok) this.openEdit(res.data);
  });
```
